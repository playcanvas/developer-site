# Assets

The PlayCanvas Editor provides a complete asset management system for your project. This section covers how to work with assets in the Editor, including importing, organizing, and configuring them.

## What You'll Learn

- **[Assets Panel](https://developer.playcanvas.com/user-manual/editor/assets/asset-panel.md)** - Navigate and manage your project's assets using the Assets Panel
- **[Importing Assets](https://developer.playcanvas.com/user-manual/editor/assets/importing.md)** - Upload and import assets into your project
- **[Import Pipeline](https://developer.playcanvas.com/user-manual/editor/assets/import-pipeline.md)** - Configure how assets are processed during import
- **[Asset Inspectors](https://developer.playcanvas.com/user-manual/editor/assets/inspectors.md)** - Configure asset properties using the Inspector
- **[Asset Store](https://developer.playcanvas.com/user-manual/editor/assets/asset-store.md)** - Browse and import assets from the PlayCanvas Asset Store
- **[Asset Viewers](https://developer.playcanvas.com/user-manual/editor/assets/viewers.md)** - Inspect models and textures in dedicated viewer tools

## Overview

Assets in the Editor are managed through the [Assets Panel](https://developer.playcanvas.com/user-manual/editor/assets/asset-panel.md), which provides a visual interface for:

- Organizing assets into folders
- Uploading new assets via drag-and-drop
- Searching and filtering assets
- Inspecting and editing asset properties
- Copying assets between projects

When you upload a file, the Editor runs it through the [import pipeline](https://developer.playcanvas.com/user-manual/editor/assets/import-pipeline.md) to convert and optimize it for use in your application. The resulting asset can then be configured using the appropriate [asset inspector](https://developer.playcanvas.com/user-manual/editor/assets/inspectors.md).

For conceptual information about assets and how to work with them programmatically, see the [Assets](https://developer.playcanvas.com/user-manual/assets.md) section in Common Topics.
