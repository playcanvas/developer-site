# Web

PlayCanvas games are actually web pages and as such, are most at home in the browser. When publishing on the web, you have a number of options:

* [PlayCanvas Hosting](https://developer.playcanvas.com/user-manual/editor/publishing/web/playcanvas-hosting.md)
* [Self-hosting](https://developer.playcanvas.com/user-manual/editor/publishing/web/self-hosting.md)
* [heyVR.io](https://developer.playcanvas.com/user-manual/editor/publishing/web/hosting-heyvr.md)
