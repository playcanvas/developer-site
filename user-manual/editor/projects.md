# Projects

## Overview

Projects are the foundation for everything you create in the PlayCanvas Editor. A project contains all the assets, scenes, scripts, and settings needed to build your application or game. This section covers all aspects of project management, from creation to configuration.

## Project Management Topics

### Getting Started

- **[Creating Projects](https://developer.playcanvas.com/user-manual/editor/projects/creating.md)** - How to create new projects.

### Working with Projects

- **[Project Dashboard](https://developer.playcanvas.com/user-manual/editor/projects/dashboard.md)** - Understanding and navigating the project dashboard interface.
- **[Project Settings](https://developer.playcanvas.com/user-manual/editor/projects/settings.md)** - Configure your project's name, description, privacy, and branding.
- **[Team Management](https://developer.playcanvas.com/user-manual/editor/projects/team-management.md)** - Adding collaborators and managing permissions.
- **[Development Logs](https://developer.playcanvas.com/user-manual/editor/projects/dev-logs.md)** - Using dev logs for project updates and team communication.
- **[Downloading Projects](https://developer.playcanvas.com/user-manual/editor/projects/downloading.md)** - Download app packages and choose static or npm package formats.

### Advanced Management

- **[Backup and Export](https://developer.playcanvas.com/user-manual/editor/projects/backup-and-export.md)** - Protecting your projects with backups and exports.
- **[Ownership and Transfers](https://developer.playcanvas.com/user-manual/editor/projects/ownership-transfers.md)** - Transferring projects between users and organizations.

## Quick Actions

Once you understand the basics of project management, you can:

- Access the [Editor](https://developer.playcanvas.com/user-manual/editor/interface.md) to build your project.
- Test your project using the [Launch Page](https://developer.playcanvas.com/user-manual/editor/interface/launch-page.md).
- Use [Real-time Collaboration](https://developer.playcanvas.com/user-manual/editor/realtime-collaboration.md) to build with others.
- Use [Version Control](https://developer.playcanvas.com/user-manual/editor/version-control.md) to manage your development workflow.
