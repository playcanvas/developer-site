# Toolbar

The Editor's main toolbar can be found on the left, vertical edge of the Editor. You can access many common operations via the toolbar. Here is a list of the functionality available:

| Button | Command | Description |
| ------ | ------- | ----------- |
| [Image: Menu] | **Menu** | Open the main menu to access the most commonly needed Editor functions. |
| [Image: Gizmo Translate] | **Translate** | Activate the translate [gizmo](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md#gizmos) in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md). |
| [Image: Gizmo Rotate] | **Rotate** | Activate the rotate [gizmo](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md#gizmos) in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md). |
| [Image: Gizmo Scale] | **Scale** | Activate the scale [gizmo](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md#gizmos) in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md). |
| [Image: Element Scale] | **Resize Element** | Activate the User Interface [Element resizing gizmo](https://developer.playcanvas.com/user-manual/user-interface/elements.md#element-resizing) in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md).  |
| [Image: World Local] | **World/Local** | Switch between local and world coordinate systems for the active [gizmo](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md#gizmos) in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md). |
| [Image: Snap] | **Snap** | Enable snapping when using the [gizmos](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md#gizmos) in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md). |
| [Image: Focus] | **Focus** | Zoom the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md) camera to the currently selected Entity. |
| [Image: Undo] | **Undo** | Undo the last operation. |
| [Image: Redo] | **Redo** | Redo the last operation. |
| [Image: Bake] | **Lightmapper** | Access the [Lightmapper](https://developer.playcanvas.com/user-manual/graphics/lighting/runtime-lightmaps.md) bake and auto-rebake controls. |
| [Image: Code Editor] | **Code Editor** | Open the [Code Editor](https://developer.playcanvas.com/user-manual/editor/scripting/code-editor.md). |
| [Image: Publish] | **Publish / Download** | [Publish a build](https://developer.playcanvas.com/user-manual/editor/publishing/web/playcanvas-hosting.md#publishing-a-new-build) or download your project. |
| [Image: GitHub] | **GitHub** | Report issues on [GitHub](https://github.com/playcanvas/editor/issues). |
| [Image: Discord] | **Discord** | Join the PlayCanvas [Discord server](https://discord.gg/RSaMRzg). |
| [Image: Forum] | **Forum** | Ask for help on the [forum](https://forum.playcanvas.com). |
| [Image: How Do I] | **How Do I...?** | Toggle the 'How Do I...?' help widget in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md). |

| [Image: Settings] | **Settings** | Load Editor and Scene Settings into the [Inspector](https://developer.playcanvas.com/user-manual/editor/interface/inspector.md). |

## Customizing the toolbar

Since Editor 2.30.3 you can hide buttons you never use and reorder the rest.

[Video](https://developer.playcanvas.com/video/editor-toolbar-customization.mp4)

Right-click anywhere on the toolbar to open its context menu:

| Command | Description |
| ------- | ----------- |
| **Edit Toolbar** | Enter edit mode. |
| **Done Editing** | Leave edit mode. Shown in place of Edit Toolbar while editing. |
| **Reset Toolbar** | Restore the default buttons and order. Only shown once you have hidden or moved something. |

In edit mode:

- Each button gains an **eye** badge. Click it to hide or show that button. Hidden buttons stay visible, dimmed, while you are editing so you can bring them back.
- Buttons can be dragged to reorder them. The toolbar has two groups — the commands at the top and the utility buttons at the bottom — and a button can only be moved within its own group.
- The **Menu** button at the top of the toolbar becomes a **Done editing toolbar** button. Click it, or pick **Done Editing** from the context menu, to finish.

:::note

Your layout is saved in your browser rather than in the project, so it applies to every project you open in that browser and is not shared with your collaborators.

:::
