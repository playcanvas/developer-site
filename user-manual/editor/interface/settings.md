# Project Settings

Project Settings control how your project runs and how the Editor behaves for your team. They include engine/runtime configuration (rendering, physics, input, network), asset import defaults, and Editor preferences. Some settings apply only to you (session or user-specific), while most affect all collaborators on the current branch.

## Opening Settings

Load the Settings into the [Inspector](https://developer.playcanvas.com/user-manual/editor/interface/inspector.md) by clicking the 'cog' icon on the [Toolbar](https://developer.playcanvas.com/user-manual/editor/interface/toolbar.md) or in the [Viewport](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md).

## Settings Overview

Settings are grouped into categories, where each category is shown as a collapsible panel. These categories are listed in the Inspector in the following order:

| Panel | Description |
| --- | --- |
| [Engine](https://developer.playcanvas.com/user-manual/editor/interface/settings/engine.md) | Engine settings, including the engine version. |
| [Editor](https://developer.playcanvas.com/user-manual/editor/interface/settings/editor.md) | Editor settings such as camera near/far clip, zoom sensitivity, and more. |
| [Asset Import](https://developer.playcanvas.com/user-manual/editor/interface/settings/asset-import.md) | Settings for controlling how assets are imported into your project. |
| [Physics](https://developer.playcanvas.com/user-manual/editor/interface/settings/physics.md) | Physics settings to include the library and set gravity. |
| [Rendering](https://developer.playcanvas.com/user-manual/editor/interface/settings/rendering.md) | Rendering settings such as skybox, clustered lighting, shadow settings, and more. |
| [Layers](https://developer.playcanvas.com/user-manual/editor/interface/settings/layers.md) | Manage rendering layers and their order. |
| [Lightmapping](https://developer.playcanvas.com/user-manual/editor/interface/settings/lightmapping.md) | Lightmapping settings such as resolution, mode, and ambient bake. |
| [Batch Groups](https://developer.playcanvas.com/user-manual/editor/interface/settings/batch-groups.md) | Manage batch groups for this project. Batch groups reduce draw calls by batching similar models and elements together. |
| [Launch Page](https://developer.playcanvas.com/user-manual/editor/interface/settings/launch-page.md) | Settings for the launch page. |
| [Input](https://developer.playcanvas.com/user-manual/editor/interface/settings/input.md) | Enable or disable input devices (mouse, keyboard, etc.). |
| [Localization](https://developer.playcanvas.com/user-manual/editor/interface/settings/localization.md) | Settings for adding localization assets. |
| [Network](https://developer.playcanvas.com/user-manual/editor/interface/settings/network.md) | Network-related settings for the project. |

:::ai
When configuration may cause unexpected behavior, ask an AI assistant through the **[Editor MCP Server](https://developer.playcanvas.com/user-manual/editor/mcp-server.md)** to identify relevant settings and scopes, then explain the smallest change before you apply it.
:::
