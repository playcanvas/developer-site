# Editor Interface

[Image: Editor Interface]

This is the main interface to the PlayCanvas Editor. The numbered areas above are:

1. [**Toolbar**](https://developer.playcanvas.com/user-manual/editor/interface/toolbar.md) Commonly used commands are available on the toolbar for quick access.
2. [**Hierarchy**](https://developer.playcanvas.com/user-manual/editor/interface/hierarchy.md) A hierarchical view of the Entities that make up the open Scene. Use this to select, delete and re-parent Entities.
3. [**Viewport**](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md) A 3D view onto your scene, use this view to select, position and orientate Entities.
4. [**Inspector**](https://developer.playcanvas.com/user-manual/editor/interface/inspector.md) Detailed properties of the selected [Entity](https://developer.playcanvas.com/user-manual/glossary.md#entity), [Asset](https://developer.playcanvas.com/user-manual/glossary.md#asset) or [Component](https://developer.playcanvas.com/user-manual/glossary.md#component).
5. [**Assets**](https://developer.playcanvas.com/user-manual/editor/interface/assets.md) A view of all the Assets in the current Project. You can search for assets by name, filter by type and also drag and drop assets to various slots or in the Design View.
