# Examples

Less talking, more doing. Each example below runs live on the page and is fully editable — change the code and the scene updates instantly. Together they show how components, hooks, asset loading and physics come together in a real PlayCanvas React app.

[Model Viewer](https://developer.playcanvas.com/user-manual/react/examples/model-viewer.md): Load a glb model with environment lighting, a shadow catcher and auto-rotating orbit controls.
[Motion](https://developer.playcanvas.com/user-manual/react/examples/motion.md): Animate entities and lights with springs from the Motion animation library.
[Physics](https://developer.playcanvas.com/user-manual/react/examples/physics.md): Disturb a cluster of rigid bodies in zero gravity with the pointer.
[Text](https://developer.playcanvas.com/user-manual/react/examples/text.md): Render screen-space UI text with a Screen and a text Element, using an MSDF font from font-tools.

Want to build something of your own? Spin up a full project in seconds with the [StackBlitz template](https://playcanvas-react.vercel.app/new), or browse the [interactive playground](https://playcanvas-react.vercel.app/examples) for more live examples.

New to PlayCanvas React? Start with the [Guide](https://developer.playcanvas.com/user-manual/react/guide.md) to see how scenes are composed, then explore the [API reference](https://developer.playcanvas.com/user-manual/react/api.md).
