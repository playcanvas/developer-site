# Installation

The recommended way to get started is to use the official [`create-playcanvas`](https://developer.playcanvas.com/user-manual/getting-started/start-with-create-playcanvas.md) scaffolding tool and choose the React format:

```bash
npm create playcanvas@latest my-app -- -f react
```

Choose one of the 12 runnable starters when prompted. The generated TypeScript project includes Vite, development and production scripts, and [PlayCanvas Skills](https://developer.playcanvas.com/user-manual/getting-started/use-playcanvas-skills.md) for compatible AI coding agents.

We recommend following [this guide](https://developer.playcanvas.com/user-manual/react/building-a-scene.md) to start building your first project.

## Manual Installation

If you have an existing project, just install `@playcanvas/react` using your preferred package manager.

**npm**

```bash
npm install @playcanvas/react playcanvas
```

**yarn**

```bash
yarn add @playcanvas/react playcanvas
```

**pnpm**

```bash
pnpm add @playcanvas/react playcanvas
```

Once installed, you can start using it in your project. As the next step, we recommend following the [building a scene guide](https://developer.playcanvas.com/user-manual/react/building-a-scene.md) to create your first project.
