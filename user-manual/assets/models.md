# Importing 3D Models

3D models and animations are imported into PlayCanvas by uploading scene files from a [3D modeling application](https://developer.playcanvas.com/user-manual/assets/models/building.md) such as [Blender](https://www.blender.org/), 3D Studio Max or Maya.

PlayCanvas supports a wide variety of formats, such as glTF binary (GLB), FBX, COLLADA and obj. We recommend using the GLB format for best results.

Uploading one of these files will create a [Source Asset](https://developer.playcanvas.com/user-manual/glossary.md#source-asset) of type 'Model' and will produce several [Target Assets](https://developer.playcanvas.com/user-manual/glossary.md#target-asset) including a '[Template](https://developer.playcanvas.com/user-manual/editor/assets/inspectors/template.md)' with the model hierarchy and 'Render' assets. You can add an instance of the 'Template' in your game.
