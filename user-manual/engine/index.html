PlayCanvas Engine

The PlayCanvas Engine is an open-source 3D engine for the web. It renders with WebGPU or WebGL 2 in any modern browser, on desktop and mobile, and it's the foundation that the Editor, PlayCanvas React and Web Components are built on.

Your First App​

This is a complete Engine app. It is running right here in the page, and you can edit it: the preview reruns as you type.

Live Example
import * as pc from 'playcanvas';

// create a graphics device, preferring WebGPU over WebGL 2
const canvas = document.getElementById('application');
const device = await pc.createGraphicsDevice(canvas, {
    deviceTypes: [pc.DEVICETYPE_WEBGPU]
});
device.maxPixelRatio = Math.min(window.devicePixelRatio, 2);

// create an application with the component systems it uses
const options = new pc.AppOptions();
options.graphicsDevice = device;
options.componentSystems = [
    pc.RenderComponentSystem,
    pc.CameraComponentSystem,
    pc.LightComponentSystem
];

const app = new pc.AppBase(canvas);
app.init(options);
app.setCanvasFillMode(pc.FILLMODE_FILL_WINDOW);
app.setCanvasResolution(pc.RESOLUTION_AUTO);
window.addEventListener('resize', () => app.resizeCanvas());
app.start();

// light the scene softly from all around
app.scene.ambientLight = new pc.Color(0.3, 0.3, 0.35);

// create a camera looking down at the middle of the grid
const camera = new pc.Entity('camera');
camera.addComponent('camera', {
    clearColor: new pc.Color(0.12, 0.14, 0.17)
});
camera.setPosition(0, 7, 17);
camera.lookAt(0, 0, 0);
app.root.addChild(camera);

// create a sun that casts shadows
const light = new pc.Entity('light');
light.addComponent('light', {
    castShadows: true,
    shadowDistance: 40,
    shadowBias: 0.2,
    normalOffsetBias: 0.05
});
light.setEulerAngles(45, 30, 0);
app.root.addChild(light);

// create a grid of boxes, shading from orange in the middle to purple at the edges
const size = 10;
const orange = new pc.Color(1, 0.4, 0.1);
const purple = new pc.Color(0.4, 0.2, 1);
const boxes = [];
for (let x = -size; x <= size; x++) {
    for (let z = -size; z <= size; z++) {
        const material = new pc.StandardMaterial();
        material.diffuse.lerp(orange, purple, Math.hypot(x, z) / (size * 1.5));
        material.update();

        const box = new pc.Entity();
        box.addComponent('render', { type: 'box', material: material });
        box.setPosition(x, 0, z);
        app.root.addChild(box);
        boxes.push(box);
    }
}

// every frame, ripple the boxes' heights out from the middle
let time = 0;
app.on('update', (dt) => {
    time += dt;
    for (const box of boxes) {
        const { x, z } = box.getPosition();
        const height = 2.2 + 2 * Math.sin(time * 3 - Math.hypot(x, z) * 0.5);
        box.setLocalScale(0.9, height, 0.9);
    }
});

The first lines are the same in every Engine app. createGraphicsDevice asks for WebGPU and falls back to WebGL 2 where the browser doesn't support it. AppBase is the application: it runs the frame loop, but only the component systems you register, so a bundler can leave the others out of your build. Everything in the scene is an entity in a hierarchy under app.root, and components give each entity its abilities: here a camera, a sun that casts shadows, and 441 boxes, each rendered with its own material. Every frame, the update event passes your code the time since the last one, which it uses to ripple the boxes. Some things to try:

  • Speed the ripple up by raising the 3 in time * 3, or tighten its rings by raising the 0.5.
  • Swap orange and purple for any two colors you like.
  • Grow the grid by changing size to 20: that's 1,681 boxes.
  • Turn the boxes into columns with type: 'cylinder'.

To build an app like this on your own machine, run npm create playcanvas@latest and pick the Engine format, or follow Using the Engine Standalone to set a project up by hand.

Why the PlayCanvas Engine?​

  • WebGPU and WebGL 2 from one codebase. Ask for WebGPU and the engine falls back to WebGL 2 in browsers that don't support it yet, with the same API and the same look. See Supported Browsers for where each one runs.
  • Batteries included. Rigid-body physics, state-based animation, positional sound, 2D and 3D user interfaces, WebXR for AR and VR, Gaussian splats, and mouse, keyboard, touch and gamepad input are all built in. The package also ships ready-made scripts for camera controls, character controllers, XR, post effects and more.
  • Lean by design. The engine is published as ES modules, and AppBase runs only the component systems and resource handlers you register, so a bundler can leave out the ones your app doesn't use.
  • Assets that load fast. Models load from glTF 2.0 files with Draco geometry and Basis texture compression, and large Gaussian splat scenes stream in by level of detail as the camera moves.
  • TypeScript ready. The npm package ships complete TypeScript declarations, so your editor can complete and check every class, method and property, whether you write TypeScript or JavaScript.
  • Runs where JavaScript runs. As well as in the browser, the engine runs headless in Node.js, for multiplayer servers, asset tools and unit tests.
  • Open source and proven in production. The engine is developed in the open on GitHub under the MIT license, free for personal and commercial projects. It powers the PlayCanvas Editor and SuperSplat, as well as every app built with the Editor, PlayCanvas React or Web Components.
