# PlayCanvas Editor

The PlayCanvas Editor is a powerful, browser-based development environment for creating stunning 3D applications. No downloads, no installations—just open your browser and start building.

[Image: PlayCanvas Editor Interface]

## Why Choose the PlayCanvas Editor?

### 🌐 Accessible Anywhere

The entire Editor runs in your web browser. Whether you're at your desk, on a laptop, or borrowing a friend's computer, your projects are just a login away. Your work is automatically saved to the cloud, so you never lose progress.

### 👁️ What You See Is What You Get

The Editor uses the same [PlayCanvas Engine](https://developer.playcanvas.com/user-manual/engine.md) that powers your published applications. Every material, every light, every shadow you see in the Editor is exactly what your users will experience. No surprises at runtime.

### ⚡ Instant Iteration

Make a change, see it instantly. With [live editing](https://developer.playcanvas.com/user-manual/editor/scripting/hot-reloading.md), you can tweak materials, adjust positions, and even modify scripts while your application runs. Hit the [Launch](https://developer.playcanvas.com/user-manual/editor/interface/launch-page.md) button and your project opens in a new tab, ready to test. The feedback loop between idea and implementation has never been shorter.

## Built for Teams

### Real-time Collaboration

[Image: Collaboration in the Viewport]

Work together with your team in real-time. See where others are looking, what they're selecting, and chat directly within the Editor. Multiple developers, artists, and designers can build the same scene simultaneously—no merge conflicts, no stepping on each other's toes. [Learn more about collaboration →](https://developer.playcanvas.com/user-manual/editor/realtime-collaboration.md)

### Professional Version Control

[Image: Version Control Graph]

PlayCanvas includes a complete [version control system](https://developer.playcanvas.com/user-manual/editor/version-control.md) designed specifically for 3D projects:

- **Checkpoints** — Snapshot your project at any point and roll back if needed
- **Branches** — Develop features in isolation without affecting the main project
- **Merging** — Combine work from multiple branches with visual conflict resolution
- **History** — Track every change to every asset and entity over time

## Complete Development Toolkit

### Visual Scene Building

Construct your 3D worlds using intuitive [transform gizmos](https://developer.playcanvas.com/user-manual/editor/interface/viewport.md), a hierarchical [entity tree](https://developer.playcanvas.com/user-manual/editor/interface/hierarchy.md), and a comprehensive [property inspector](https://developer.playcanvas.com/user-manual/editor/interface/inspector.md). Drag and drop assets directly into your scene, parent entities with a click, and fine-tune every detail.

### Integrated Code Editor

Write scripts without leaving your browser. The built-in [code editor](https://developer.playcanvas.com/user-manual/editor/scripting/code-editor.md) features syntax highlighting, intelligent autocomplete, and real-time error checking. For larger projects, use the [VS Code extension](https://developer.playcanvas.com/user-manual/editor/scripting/vscode-extension.md) and develop locally with full IDE power.

### Powerful Asset Pipeline

Import models, textures, audio, and more with a streamlined [asset pipeline](https://developer.playcanvas.com/user-manual/editor/assets/import-pipeline.md). The Editor automatically optimizes your assets and handles format conversions. Organize everything in the [Assets Panel](https://developer.playcanvas.com/user-manual/editor/assets/asset-panel.md) with folders, search, and filtering.

### Component-Based Architecture

Build complex behaviors by combining [components](https://developer.playcanvas.com/user-manual/editor/scenes/components.md)—camera, light, physics, audio, scripts, and more. This modular approach keeps your project organized and your code reusable.
