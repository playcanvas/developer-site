# User Profile

Each creator on SuperSplat gets a public profile at `https://superspl.at/user?id=<username>`. The profile shows their avatar, display name, bio, any social links they've added, and a grid of every **Public** splat they've published.

Profiles are linked from the **author chip** that appears on every [scene page](https://developer.playcanvas.com/user-manual/supersplat/scene-page.md) and on every card in the [Explore](https://developer.playcanvas.com/user-manual/supersplat/explore.md) grid — clicking the author's name navigates to their profile.

Browsing a profile is anonymous; no PlayCanvas account is required.

[Image: A creator's SuperSplat profile page — avatar, display name, social links, and a grid of their public splats]

## What's shown

| Section | What it contains |
|---------|------------------|
| **Avatar and display name** | The creator's PlayCanvas account avatar and chosen display name. |
| **Bio** | A short profile description the creator has written about themselves. |
| **Social links** | Links to any external profiles the creator has added (X, LinkedIn, personal site, etc.). |
| **Splat grid** | Every **Public** splat the creator has published, using the same card UI as [Explore](https://developer.playcanvas.com/user-manual/supersplat/explore.md). Click any card to open its [scene page](https://developer.playcanvas.com/user-manual/supersplat/scene-page.md). |

Unlisted splats are not shown on the public profile — only the creator can see those, via the [Manage page](https://developer.playcanvas.com/user-manual/supersplat/manage.md).
