ビジュアルに作る

ブラウザで動く共同編集エディターで、シーンの組み立てからスクリプトの追加、公開までを行えます。インストールは不要です。

最初のアプリを作成5分エディターのチュートリアル→
$ npm create playcanvas@latest
◆ Select a format:
│ ● Engine
│ ○ React
│ ○ Web Components
└

create-playcanvas

コードで作る

12個の実行可能なスターターから選んで、Engine、React、Web Components用のViteとTypeScriptのプロジェクトを作成できます。

サンプルで学ぶ

ライブサンプルを動かし、ソースコードを読んで、自分のプロジェクトに応用しましょう。

エンジンの例レンダリングや物理演算からスプラット、XRまで、ソースコード付きのライブサンプルが数百種類あります。エディターのチュートリアルEditorでゲームやインタラクティブなアプリを作るためのステップバイステップのガイド。React の例@playcanvas/reactで作られたモデルビューア、物理演算、モーション、テキストのサンプル。Web Components の例最初のシーンから本格的なショーケースまで、実際に動かして探索できるHTMLページ。

AIで開発する

コーディングエージェントにPlayCanvasの知識を。Skills、Editor MCP Server、エージェント向けのドキュメントが、Claude Code、Codex、Cursorなどのエージェントによるアプリの構築と検証を支援します。

npx skills add playcanvas/skills
  • PlayCanvas SkillsEngine、React、Web Componentsのアプリを構築、検証するためのワークフロー。
  • Editor MCP ServerエージェントをEditorに接続して、プロジェクトを変更、検証します。
  • AI を活用した開発Engineプロジェクトにコーディングエージェントを導入し、その変更を確認します。
  • llms.txt各ページのMarkdown版へエージェントを案内するインデックス。
