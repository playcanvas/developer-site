カメラアニメーション

カメラアニメーションは、キーフレームで定義したパスに沿ってカメラを動かします。オブジェクトの周りを穏やかに回るターンテーブルから、キャプチャした空間の本格的なフライスルーまで作れます。Studioでは、Timelineパネルで作成し、SceneタブのAnimationセクションで制御します。訪問者はシーンページでそれを見ることができ、いつでも一時停止したりカメラを操作したりできます。

シーンが持てるカメラアニメーションは1つです。Editorのタイムラインのアニメーション付きでスプラットを公開した場合、Studioはそのアニメーションを読み込んだ状態で開き、すぐに編集できます。

タイムラインパネル​

ヘッダーのTimelineをクリックするかTを押すと、Studioの下部のパネルを表示または非表示にできます。

コントロール動作
Previous keyframe / Next keyframe再生ヘッドを隣のキーフレームにジャンプします。
Step back one frame / Step forward one frame再生ヘッドを1フレーム移動します。
Play / Pauseビューポートでアニメーションを再生します（Space）。カメラ編集モード中は使えません。
Add keyframe at playheadビューポートのカメラを再生ヘッドの位置にキーフレームとして保存します（Enter）。
Delete selected keyframes選択したキーフレームを削除します。選択中のキーフレーム数が横に表示されます。
フレーム表示再生ヘッドのフレームと総フレーム数。
Durationアニメーションの長さ（秒、0.1～600）。
FPSタイムラインの1秒あたりのフレーム数（1～120）。アニメーションのフレーム数はDuration × FPSです。
Loop modePlay once、Loop（デフォルト）、Ping-pong（順方向に再生した後、逆方向に再生することを繰り返す）。
Smoothキーフレーム間のパスの滑らかさ。0（直線）から1（デフォルト、滑らかな曲線）まで。
Hide timelineパネルを閉じます。

コントロールの下のCameraトラックには、キーフレームごとのマーカーが付いたルーラーが表示されます。ルーラーをクリックまたはドラッグすると再生ヘッドが移動します。トラックのゴミ箱アイコンDelete camera animationは、すべてのキーフレームとともにアニメーションを削除します。

キーフレームの作成​

  1. タイムラインを開き、再生ヘッドを目的のフレームに移動します。
  2. ビューポートでショットをフレーミングします。
  3. Add keyframe at playheadをクリックするか、Enterを押します。そのフレームにすでにキーフレームがある場合は置き換えられます。
  4. 再生ヘッドを移動して繰り返します。

各キーフレームには、カメラの位置、ターゲット、視野角が保存されます。最初のキーフレームを追加すると、Play animation on openもオンになります。

キーフレームの編集​

  • 選択: キーフレームをクリックします。Ctrlキーを押しながらクリック（macOSではCmdキー）すると選択に追加または選択から除外でき、トラックの空いている部分をドラッグすると範囲内のすべてのキーフレームを選択できます。
  • 移動: 選択をトラックに沿ってドラッグします。
  • コピー: Shiftキーを押しながらドラッグします。
  • 変更: 再生ヘッドをキーフレームに移動し、新しいショットをフレーミングして、もう一度キーフレームを追加します。

タイムラインの編集はすべてCtrl+Z（macOSではCmd+Z）で元に戻せます。

滑らかなループ

Loop modeがLoopの場合、カメラは残りのフレームを使って最後のキーフレームから最初のキーフレームへ戻ります。最後のキーフレームの後にフレームを残し、最初と最後の両方のフレームにキーフレームを置かないでください。そうしないとループ時にカメラが飛びます。

開いたときの再生​

SceneタブのAnimationセクションには、Play animation on openというスイッチが1つあります：

  • オン: シーンページを開くとすぐにアニメーションが再生されます。訪問者は一時停止したりカメラを操作したりできます。
  • オフ: シーンは開始カメラで開き、アニメーションは再生されません。

スイッチがオフのままアニメーションにキーフレームがある場合、タイムラインにViewer won't play this animationと表示され、Play on openボタンでスイッチをオンにできます。

Saveをクリックしたとき、キーフレームのないアニメーションは保存されず、シーンは開始カメラで開きます。

EditorとStudioでのアニメーション​

Editorのタイムラインでカメラのキーフレームを作成し、スプラットと一緒にアニメーションを公開することもできます。どちらも同じアニメーションを編集するため、最後に保存したほうが有効になります。Override Animationを有効にしてEditorから再公開すると、Studioで作成したアニメーションは置き換えられます。すでに公開済みのスプラットでは、公開されたビューアで結果をすぐに確認できるStudioのほうが手早く作業できます。
