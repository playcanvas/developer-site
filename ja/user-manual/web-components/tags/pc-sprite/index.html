<pc-sprite>

<pc-sprite>タグは、エンティティの位置に2D画像を描画するスプライトコンポーネントを追加します。キャラクター、コイン、地面の帯、背景の層などです。simpleスプライトはスプライトアセットの1つのフレームを表示し、animatedスプライトは子として持つ<pc-sprite-clip>を再生します。

使用法
  • <pc-entity>、<pc-model>、または<pc-node>の直接の子である必要があります。
  • 0..n個の<pc-sprite-clip>を子として持つことができ、それぞれが1つの名前付きクリップを宣言します。これらを再生するのはanimatedスプライトだけです。

スプライトアセット​

スプライトは2種類の<pc-asset>から描画されます。アトラスを先に宣言します。

  1. textureatlasアセット: すべてのフレームを収めた1枚の画像と、dataのJSONです。そのframesオブジェクトが各フレームに名前を付け、画像内の位置を示します。フレームのrectは[x, y, width, height]をピクセル単位で表し、画像の左下の角から測ります。pivotはエンティティの位置に置かれる点で、[0, 0]（左下）から[1, 1]（右上）までの値を取ります。[0.5, 0]にすると、キャラクターが足元で立ちます。9スライス用のフレームにはborderもあり、[left, bottom, right, top]をピクセル単位で指定します。
  2. アトラスから切り出した1つ以上の**sprite**アセット: atlasでアトラスを指定し、frame-keysでスプライトを構成するフレームを順に列挙し、pixels-per-unitでサイズを決めます。高さ24ピクセルのフレームは、pixels-per-unit="16"ではワールド単位で1.5の高さになります。render-modeは、スプライトが独自のサイズをどう埋めるかを決めます。タイルとスライスのスプライトを参照してください。
<pc-app>
    <!-- アトラス: 1枚の画像と、その中の各フレームの位置 -->
    <pc-asset id="atlas" type="textureatlas" src="sprites.png"
              srgb mipmaps="false" min-filter="nearest" mag-filter="nearest"
              data='{ "frames": {
                  "coin-0": { "rect": [0, 0, 12, 12], "pivot": [0.5, 0.5] },
                  "coin-1": { "rect": [12, 0, 12, 12], "pivot": [0.5, 0.5] },
                  "coin-2": { "rect": [24, 0, 12, 12], "pivot": [0.5, 0.5] },
                  "platform": { "rect": [201, 46, 28, 16], "pivot": [0.5, 1], "border": [6, 0, 6, 0] }
              } }'></pc-asset>
    <!-- アトラスから切り出したスプライト: フレームの並びと、そのスケール -->
    <pc-asset id="coin" type="sprite" atlas="atlas" frame-keys="coin-0 coin-1 coin-2" pixels-per-unit="16"></pc-asset>
    <pc-asset id="platform" type="sprite" atlas="atlas" frame-keys="platform" pixels-per-unit="16" render-mode="tiled"></pc-asset>
    <pc-scene>
        <pc-entity name="coin" position="0 1 0">
            <pc-sprite asset="coin"></pc-sprite>
        </pc-entity>
    </pc-scene>
</pc-app>

スプライトのフレームは、そのスプライトが表示できるものです。simpleスプライトはその1つをframeで選んで描画するため、1つのスプライトアセットでバリエーションの組を提供できます。Spritesサンプルは、草原の花、キノコ、岩をすべて6フレームのdecorスプライト1つから描いています。animatedスプライトのクリップは、それぞれのスプライトのフレームを順に再生します。

ピクセルアート​

ピクセルアートには、アトラスに4つのテクスチャオプションが必要です。上の例ではすべて設定しています。

  • min-filter="nearest"とmag-filter="nearest"は、各ピクセルを角の立った正方形としてサンプリングします。デフォルトの線形フィルタリングは隣り合うピクセルを混ぜるため、小さな画像を大きく描くとぼやけます。
  • mipmaps="false"は、テクスチャの縮小済みでぼかされたコピーを無効にします。これがあると、ピクセルサイズより小さく描かれたスプライトがそれをサンプリングし、ぼやけるうえに、アトラス内の隣のフレームが縁ににじみ込みます。
  • srgbは画像をガンマエンコードされたカラーとして扱います。画像編集ソフトで描いたPNGが保持しているのはこの形式なので、描いたとおりの色でスプライトが表示されます。指定しないと色が薄く出ます。

画面上でピクセルが正方形のまま保たれるのは、各ピクセルが画面の整数個のピクセルを覆うときだけです。正射影カメラでは、Spritesサンプルのスクリプトがウィンドウのリサイズのたびに行っているように、キャンバスの高さからortho-heightを決める必要があります。

属性​

属性タイプデフォルト説明
assetAsset ID-描画するスプライトのスプライトアセットID（sprite型アセットを参照する必要があります）。simpleスプライトのみ: animatedスプライトはクリップからフレームを取ります。空の場合は何も描画しません
clipString-再生するクリップの名前（animatedスプライトのみ）。変更すると再生が切り替わり、同じ名前を再び設定すると、終了したクリップが最初から再生されます。クリップの再生を参照してください
colorColor"1 1 1 1"スプライトに付ける色。テクスチャの色に乗算されます。アルファは無視されるため、透明度にはopacityを使用します
enabledBoolean"true"コンポーネントの有効状態
flip-xBoolean"false"スプライトを左右反転するかどうか。たとえばキャラクターを反対向きにするときに使います
flip-yBoolean"false"スプライトを上下反転するかどうか
frameNumber"0"描画するフレームのインデックス。現在のスプライトのフレームキーの中で数えます。animatedスプライトでは、設定すると再生中のクリップがそのフレームへ移り、そこから再生が続きます。ただしクリップは常に最初のフレームから始まるため、マークアップで指定したframeは効果がありません
heightNumber"1"スプライトの高さ（ワールド単位）。スプライトアセットのrender-modeがslicedまたはtiledのときだけ使われます
opacityNumber"1"スプライトの不透明度（0〜1）
speedNumber"1"すべてのクリップに適用される再生速度の乗数。0で再生が止まります。各クリップのfpsに乗算されます
typeEnum"simple"スプライトのタイプ: "simple" | "animated"。"simple"はスプライトassetの1つのフレームを描画し、"animated"は子の<pc-sprite-clip>を、clipで指定したものから再生します
widthNumber"1"スプライトの幅（ワールド単位）。スプライトアセットのrender-modeがslicedまたはtiledのときだけ使われます
スプライトの描画方法

スプライトはライティングの影響を受けません。ライト、環境光の色、フォグ、トーンマッピングのいずれも適用されないため、スプライトはテクスチャの色にcolorを乗算した色で表示されます。スプライトはWorldレイヤーの半透明ジオメトリとして描画され、カメラの視線方向に沿って奥から手前の順にソートされ、深度は書き込みません。重なるスプライトには異なる深度を与えてください。Spritesサンプルでは、空の-10からスライムの1まで、背景をz方向に間隔を空けて配置しています。

クリップの再生​

type="animated"にすると、スプライトはフレームを表示する代わりにクリップを再生します。子の<pc-sprite-clip>がそれぞれ1つのクリップ（名前、フレームを再生するスプライトアセット、フレームレート、ループするかどうか）を宣言し、clipが再生するクリップを指定します。

<pc-sprite id="slime" type="animated" clip="idle">
    <pc-sprite-clip name="idle" asset="slime-idle" fps="8" loop></pc-sprite-clip>
    <pc-sprite-clip name="hop" asset="slime-hop" fps="12" loop></pc-sprite-clip>
    <pc-sprite-clip name="land" asset="slime-land" fps="12"></pc-sprite-clip>
</pc-sprite>

clipはライブです。マークアップ、開発者ツール、JavaScriptのどこから設定しても、再生が追従します。

  • 変更すると、指定したクリップへ即座に切り替わり、最初のフレームから再生します。スプライトのクリップはクロスフェードしません。
  • 同じ名前を再び設定すると、そのクリップが終了していれば最初から再生し直します。そのためlandのような単発のクリップは、設定するたびに再生されます。再生中のクリップはそのまま続きます。
  • スプライトを有効にすると、指定したクリップを最初のフレームから再生します。スプライトまたはそのエンティティを無効にすると再生中のものが止まるため、再び有効にする前にclipを設定して、戻ったときに再生するものを選んでください。
  • どのクリップも持たない名前を指定しても何も起こらず、警告も出ません。その名前の<pc-sprite-clip>が追加されると、それが再生されます。空のclipは、現在のクリップを再生したままにします。

ループしないクリップは最後のフレームで止まり、そのまま表示し続けます。そのときエンジンのコンポーネントがendイベントを発火するので、次の動作へ移るきっかけにできます。

import { whenReady } from '@playcanvas/web-components';

const slime = await whenReady('#slime');

slime.clip = 'land'; // プロパティと属性はどちらを使っても同じです

slime.component.on('end', (clip) => {
    if (clip.name === 'land') {
        slime.clip = 'idle';
    }
});

タイルとスライスのスプライト​

デフォルトのrender-modeであるsimpleのスプライトアセットは、フレームとちょうど同じサイズで描画され、widthとheightは効果がありません。render-mode="tiled"またはrender-mode="sliced"のものは、代わりに<pc-sprite>のwidthとheight（ワールド単位）で描画され、フレームの9スライス領域で埋められます。角はサイズを保ち、辺と中央は引き伸ばされる（sliced）か、繰り返されます（tiled）。

これで、よくある2つの用途をまかなえます。

  • タイルの繰り返し。 borderのないフレームはすべてが中央なので、tiledはフレーム全体を繰り返します。16ピクセルの草のタイル1枚で、どんな長さの地面の帯でも覆えます。
  • 任意のサイズのパネルや足場。 borderのあるフレームは端を保ちます。Spritesサンプルの足場のフレームは左右に6ピクセルのボーダーを持つため、どの足場も幅にかかわらず丸い端を保ち、中央だけが繰り返されます。
<!-- 1枚の草のタイルを、96単位の地面に沿って繰り返します -->
<pc-sprite asset="grass" width="96" height="1"></pc-sprite>

<!-- 同じ足場のスプライトを2つの幅で。端は変わりません -->
<pc-sprite asset="platform" width="2.75"></pc-sprite>
<pc-sprite asset="platform" width="4.75"></pc-sprite>

widthとheightのデフォルトはどちらも1なので、フレームがその方向にすでに1単位でない限り、それぞれ設定してください。1単位あたり16ピクセルでは、高さ16ピクセルの足場にはwidthだけで十分です。

例​

タイルで並べた草の帯、9スライスの足場、3フレームのスプライト1つから描いた3本の花、そしてアニメーションするスライムです。ボタンでスライムのclipを切り替え、flip-xをオン・オフします。足場のwidthを変えたり、スライムにcolorを付けたり、speed="0.5"を試したりしてみましょう:

Spritesサンプルは、この方法で横スクロールのステージ全体を作っています。視差のある背景、集めるコイン、足場の間を跳ねたりジャンプしたりするスライムがあります。

JavaScriptインターフェース​

SpriteComponentElement APIを使用して、<pc-sprite>要素をプログラムで作成および操作できます。

asset、clip、color、flipX、flipY、frame、height、opacity、speed、type、widthも、上記の属性に対応するプロパティとして利用できます。

componentプロパティは、この要素が追加するエンジンのSpriteComponentです。要素の準備が完了するまではnullで、属性が公開していないものはすべてここから利用できます。再生中のクリップに対するpause()、resume()、stop()、クリップを名前で取得するclip(name)、そしてスプライトのlayers、drawOrder、batchGroupIdです。クリップを切り替えるには、コンポーネントのplay(name)よりも要素のclipを使ってください。clipはスプライトが次に有効になったときに再生されるものであり、play()はそれを変更しません。

コンポーネントはクリップの再生の各段階でイベントを発火し、対象のSpriteAnimationClipを渡します。

コンポーネントのイベント説明
playクリップの再生が始まった
pause再生中のクリップが一時停止された
resume一時停止したクリップが再開された
stop再生中のクリップが、スプライトの無効化またはstop()によって停止された。別のクリップへの切り替えでは発火しません
endループしないクリップが最後のフレームに達した
loopループするクリップが最後のフレームに達し、最初からやり直した

関連項目​

  • <pc-sprite-clip> — animatedスプライトが再生する各クリップを宣言します
  • <pc-asset> — テクスチャアトラスと、そこから切り出したスプライトアセット
  • <pc-camera> — 横から見た2Dシーン向けの正射影カメラ
  • <pc-element> — ワールドではなくユーザーインターフェースの中にスプライトを描画します
