プランと請求

個人アカウントと各Organizationには、それぞれ独自のプランと請求があります。このページでは、プランを選んで購読するPlansページと、プランを管理するアカウント設定のBillingタブについて説明します。更新、通貨、返金、シートの請求方法に関する質問については、請求に関するFAQをご覧ください。

プランページ​

プランページでは、プランを比較して購読できます。プロジェクトダッシュボードで自分の名前から開くメニューのUpgrade plan、または請求タブのChange planかCompare plansから開きます。

IndividualにはFreeプランとPersonalプランが、TeamにはOrganizationプランが表示されます。プランは、表示中のアカウントに適用されます。OrganizationはOrganizationプランしか選択できないため、個人アカウントでは、Teamにプランの代わりにCreate organizationが表示されます。

購読するには、個人アカウントではUpgrade to Personalを、OrganizationではUpgrade（後ろにOrganization名が付いたボタン）を選択します。チェックアウトで支払い方法と請求先住所を入力し、Subscribeを選択します。料金は米ドルで表示され、税金は請求先の国に基づいてチェックアウト時に加算されます。日本では、料金は円建ての税込価格です。詳しくはどのような支払い方法と通貨に対応していますか？をご覧ください。

プロモーションコードをお持ちの場合は、「Have a promo code?」の下に入力し、Applyを選択します。

請求タブ​

開くには、プロジェクトダッシュボードのサイドバー下部にある自分の名前を選択し、Account settingsを選んでBillingタブを選択します。Organizationの場合は、先にページ上部のアカウント切り替えでそのOrganizationに切り替えます。

プラン​

Planには、アカウントのプランと料金、公開プロジェクトとプライベートプロジェクトの数が表示されます。有料プランの場合はプランの更新日も表示され、Organizationの場合は使用中のシート数も表示されます。Change planを選択するとプランページが開きます。右上のCompare plansからも同じページが開きます。

OrganizationプランのOrganizationでは、ここにChange seatsも表示されます。シートの追加と削除をご覧ください。

ストレージ​

Storageには、アカウントがプランのストレージ容量をどれだけ使用しているかと、その内訳が表示されます。

  • Assets - プロジェクト内の3Dモデル、テクスチャ、オーディオなどのアセットです。プロジェクトのオープンしているブランチはそれぞれ、アセットのコピーを個別に計上します。詳しくはバージョン管理がストレージに及ぼす影響をご覧ください。
  • Checkpoints - プロジェクトのバージョン履歴です。
  • Apps - 公開したアプリです。公開したビルドを削除すると、そのサイズ全体が使用量から差し引かれます。
  • Code - スクリプトなどのコードです。
  • Splats - SuperSplatに公開したGaussian splatです。

プロジェクトダッシュボードには、同じ合計がプロジェクトごとの内訳とともに表示されます。

支払い​

有料プランのアカウントにはPaymentセクションがあり、支払いに使用するカード、Billing details、VAT numberが表示されます。

  • カードの横にあるUpdateを選択すると、支払い方法を変更できます。
  • 請求先情報の横にあるEditを選択すると、請求書に記載される名前と住所を変更できます。
  • VAT番号の横にあるAddまたはEditを選択すると、VAT番号を設定できます。VAT番号を設定できるのは、請求先住所がEU、英国、スイス、ノルウェーにある場合のみです。

請求書​

Invoicesには、アカウントの過去の請求書が一覧表示され、それぞれPDFでダウンロードできます。請求書は、各請求日にアカウントのオーナーにもメールで送信されます。

プランのキャンセル​

有料プランはいつでもキャンセルできます。

  1. アカウント設定のBillingタブを開きます。
  2. Cancel planセクションでCancel planを選択し、確定します。
  3. Organizationプランを利用しているOrganizationもある場合は、ページ上部のアカウント切り替えで各Organizationに切り替え、そのBillingタブで上記の手順を繰り返します。

サブスクリプションがキャンセルされると、再購読しない限り、再度請求されることはありません。

注記

サブスクリプションをキャンセルしても、すぐにFreeプランに戻るわけではありません。プランは請求期間の終わりまで有効で、Planセクションに終了日が表示されます。その後、プライベートプロジェクトはロックされます。プランが終了する前に気が変わった場合は、Resume planを選択するとサブスクリプションを継続できます。
