3D Gaussian Splatting（3DGS）は、実在する物体や場所をキャプチャし、フォトリアルにリアルタイムで描画する手法です。多くの3Dシーンは、テクスチャとマテリアルを持つ三角形のメッシュで構成されます。一方スプラットは、**ガウシアン**と呼ばれる小さく柔らかな半透明の粒の集まりで構成されます。各ガウシアンが持つのは、位置、形、色、不透明度だけです。それらをまとめて描画すると、写真と見分けがつかないほどの画像になります。

## 粒の集まり {#a-cloud-of-blobs}

上のおもちゃの猫は、典型的な小さめのスプラットです。ドラッグして見回してから、コントロールを試してみてください。

- **ガウシアンのサイズ**を小さくしてみましょう。各ガウシアンが縮むにつれて、猫はそれを構成する個々の粒に分かれていきます。フルサイズでは粒同士が重なって溶け合い、なめらかな表面のように見えます。
- **ランダムな色**を選択すると、各ガウシアンがそれぞれ異なる色の、くっきりした形で描画されます。これで各ガウシアンの位置と大きさがわかります。なめらかな部分は大きなガウシアンが覆い、細かなディテールのある部分には小さなガウシアンが密集しています。

ここには三角形も、テクスチャも、マテリアルも、ライトもありません。陰影やハイライトも含め、目に見えるものはすべてガウシアンの色に保存されています。

:::note[スプラットとガウシアン]

**スプラット**という言葉は2つの意味で使われます。1つのガウシアンを指す場合と、ガウシアンでできたシーン全体を指す場合（「おもちゃの猫のスプラット」など）です。どちらの意味かは、たいてい文脈からわかります。

:::

## ガウシアンとは？ {#what-is-a-gaussian}

この名前は、統計学のベルカーブ（正規分布とも呼ばれます）を表すガウス関数に由来します。ガウス関数は中央で最も高く、両側に向かってなめらかに下がっていきますが、完全にゼロになることはありません。これを中心のまわりに回転させると、柔らかく丸い粒になります。さらにその粒を3つの軸に沿ってそれぞれ異なる量だけ引き伸ばすと、柔らかな楕円体、つまり**3Dガウシアン**になります。

3Dガウシアンは中心で最も濃く、端に向かってなめらかに薄れていくため、隣り合うガウシアン同士が継ぎ目なく溶け合います。スプラットでは、各ガウシアンがわずかな数値で定義されます。

| プロパティ | 数値の数 | 何を制御するか |
| --- | --- | --- |
| 位置 | 3 | 中心の位置 (x, y, z) |
| スケール | 3 | 3つの軸それぞれに沿ってどれだけ伸びるか |
| 回転 | 4 | それらの軸がどの方向を向くか（[クォータニオン](https://en.wikipedia.org/wiki/Quaternions_and_spatial_rotation)で表します） |
| 不透明度 | 1 | 中心がどれだけ不透明か |
| 色 | 3 | 基本色（赤、緑、青） |

1つのガウシアンでこれらの値を試してみましょう。色付きの棒はガウシアン自身の軸を表しています。スケールはこれらの軸に沿ってガウシアンを伸ばし、回転はこれらの軸の向きを変えます。

<GaussianPlayground />

周囲を回ってみると、どの角度から見ても柔らかな2Dの楕円に見えることに気づくでしょう。これが、ガウシアンを高速に描画できる理由です。詳しくは[スプラットの描画方法](#how-a-splat-is-drawn)で説明します。

### 見る角度で変わる色 {#color-that-changes-with-the-view}

現実の表面は、どの方向から見ても同じように見えるわけではありません。光沢のある物体の周りを動くとハイライトが表面を滑るように移動し、角度によって色が変わる素材もあります。これを捉えるために、各ガウシアンは**球面調和関数**を保存できます。球面調和関数は、見る方向によって色がどう変わるかを表す追加の数値です。

おもちゃの猫のデモで**視点依存の色**のチェックを外し、猫の目を見てみてください。目に映り込んだ反射は視点依存の色として保存されていたため、ガラスのような輝きが失われます。

球面調和関数はいくつかのバンドに分かれており、バンドが増えるほど細かな変化を表現できます。ほとんどのスプラットは3つのバンドを使用し、各ガウシアンに45個（色チャンネルごとに15個）の数値が加わります。これはスプラットのデータの大部分を占めます。圧縮されていない[PLY](formats/ply.md)ファイルでは、各ガウシアンの59個の数値のうち45個が球面調和関数です。これらを省くとスプラットは大幅に小さくなりますが、視点依存の効果は失われます。

## スプラットの作り方 {#how-a-splat-is-made}

ガウシアンを手作業で配置することはありません。スプラットは、実物を撮影した写真やビデオフレームから**トレーニング**されます。

1. 被写体の周囲全体から、重なり合う写真を数十枚から数百枚撮影します。
2. ソフトウェアが各写真の撮影位置を割り出し、被写体の表面上にあるスパースな点群を見つけます。このステップはStructure from Motionと呼ばれます。各点が1つのガウシアンになります。
3. トレーナーは、写真のうちの1枚の視点からガウシアンを描画して写真と比較し、より近づくように各ガウシアンの位置、スケール、回転、不透明度、色を少しずつ調整します。写真を順番に切り替えながら、これを何千回も繰り返します。
4. その過程で、ディテールが足りない部分のガウシアンを分割し、ほとんど寄与しないガウシアンを削除します。

各ガウシアンのどの数値も画像になめらかに影響するため、トレーナーはそれぞれの数値をどちらの方向にどれだけ調整すればよいかを計算できます。これは勾配降下法と呼ばれ、ニューラルネットワークのトレーニングにも使われている手法です。

次のビデオは、トレーニングを2Dに単純化したもので、ガウシアンがおもちゃの猫の1枚の画像を学習していきます。

左が元の画像です。中央はトレーニングが進むにつれたガウシアンの様子で、右はおもちゃの猫のデモと同じように、各ガウシアンをランダムな色のくっきりした形で描画したものです。トレーニングは数十個の大きなガウシアンから始まり、画像にディテールのある部分でそれらを分割していき、最終的に数千個になります。背景にあるもののように薄れて消えていくガウシアンは削除されます。3Dでは、ガウシアンはすべての写真に同時に一致する必要があるため、各ガウシアンは奥行き方向でも正しい位置に配置されます。

トレーニングには、ツール、ハードウェア、シーンのサイズに応じて数分から数時間かかります。自分でスプラットを作成するには、[スプラットの作成](creating/index.md)を参照してください。

## スプラットの描画方法 {#how-a-splat-is-drawn}

1フレームを描画するために、レンダラーは3つのことを行います。

![スプラットを描画する3つのステップ：各3Dガウシアンを画面上の2Dの楕円に投影し、カメラからの距離で楕円をソートし、奥から手前へブレンドする](/img/user-manual/gaussian-splatting/what-is-gaussian-splatting/drawing-ja.svg)

1. **投影。** 3Dガウシアンは、どの視点から見ても2Dのガウシアン、つまり柔らかな楕円に見えます。レンダラーは各ガウシアンの楕円が画面上のどこに来るかを計算し、それを覆う1つの矩形として描画します。
2. **ソート。** ガウシアンは半透明なので、描画する順番が重要です。レンダラーはガウシアンをカメラからの距離でソートし、カメラが動くたびにソートし直します。
3. **ブレンド。** 奥から手前の順に描画します。各ガウシアンは、その不透明度と、各ピクセルが中心からどれだけ離れているかに応じて、背後にあるものを部分的に覆います。

この過程でライティングの計算は行われず、トレースするレイも、実行するニューラルネットワークもありません。そのため、数百万個のガウシアンを含むスプラットでも、ブラウザ上で1秒間に何度も描画できます。PlayCanvasでの実装方法については、[スプラットレンダリングアーキテクチャ](rendering-architecture/index.md)を参照してください。

## スプラットとメッシュ {#splats-and-meshes}

スプラットはメッシュに取って代わるものではなく、両者はうまく組み合わせられます。PlayCanvasでは両方を同じシーンに描画できます。たとえば、スプラットの環境の中をメッシュのキャラクターが歩き回る、といった使い方です。

| | メッシュ | Gaussian splat |
| --- | --- | --- |
| **構成要素** | 三角形と、テクスチャおよびマテリアル | 柔らかく半透明なガウシアン |
| **作成方法** | 手作業でのモデリング、または写真からの再構築 | 写真やビデオによるトレーニング |
| **ライティング** | 描画時に計算されるため、変更できる | 色に取り込まれているため、固定 |
| **細かなディテール** | 毛皮、草木、ふんわりした輪郭はモデリングが難しい | 毛皮、草木、ふんわりした輪郭が自然に再現される |
| **表面** | 明確に定義されており、コリジョンや物理演算に使える | 存在しない。コリジョンメッシュを別途作成する必要がある |
| **アニメーション** | スキニングとモーフターゲット | ほぼ静的 |
| **サイズ** | 通常はコンパクト | 圧縮しないと大きい |

## 長所と制限 {#strengths-and-limitations}

スプラットが最も力を発揮するのは、実在する場所や物体を、実物どおりの見た目で再現したい場合です。

- **モデリング不要のフォトリアリズム。** 1回の撮影と1回のトレーニングが、何週間ものモデリングとテクスチャリングの代わりになることがあります。
- **モデリングが難しいディテール。** 草木、髪、毛皮、布、柔らかな輪郭が自然に見えます。
- **Webで動作。** 圧縮されたスプラットは、多くのスマートフォンを含め、ブラウザで読み込んで実行できます。

不動産や建築、建設現場の記録、文化遺産、Eコマース、バーチャルツーリズム、映画やバーチャルプロダクション、ゲーム環境などで使われています。

一方で、考慮しておくべき制限もあります。

- **ライティングが焼き込まれている。** スプラットは、撮影されたときの被写体の見た目のままです。ライティングを変えるには、[リライティング](/user-manual/gaussian-splatting/building/relighting)を参照してください。
- **表面がない。** コリジョンや物理演算には、別途メッシュやボクセルデータが必要です。[コリジョンメッシュ生成](/user-manual/splat-transform/collision)を参照してください。
- **スプラットはスナップショット。** ある瞬間を捉えたものなので、リグを組んだメッシュのように動く部分をアニメーションさせることはできません。
- **スプラットは大きい。** 数百万個のガウシアンは、大きなファイルと多くの描画処理につながります。[SOG](formats/sog.md)などの圧縮フォーマットや[LODストリーミング](building/lod-streaming.md)が役立ちます。その他のヒントは[パフォーマンス](building/performance.md)を参照してください。
- **撮影の欠点が表れる。** 写真でカバーされなかった部分は、ぼやけたり、フローターと呼ばれる宙に浮いたガウシアンが現れたりします。鏡、ガラス、非常に細い物体は再構築が困難です。[SuperSplat Editor](/user-manual/supersplat/editor/)などのツールでスプラットをクリーンアップできます。

## 誕生の経緯 {#where-it-came-from}

3D Gaussian Splattingは、2023年にInriaとマックス・プランク情報学研究所の研究者による論文[3D Gaussian Splatting for Real-Time Radiance Field Rendering](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)で発表されました。この手法は2つの既存のアイデアに基づいています。Neural Radiance Fields（NeRF）も写真からシーンを学習しますが、シーンをニューラルネットワークの中に保存するため、描画に時間がかかります。スプラッティングは1990年代初めに登場したレンダリング手法で、壁に投げつけた雪玉の跡のように、各点を画面上の柔らかな跡として描画します。学習したガウシアンの集合と高速なスプラッティングを組み合わせたことで、フォトリアルなキャプチャをリアルタイムに描画できるようになりました。
