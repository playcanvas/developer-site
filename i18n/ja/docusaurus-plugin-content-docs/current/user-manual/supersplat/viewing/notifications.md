[superspl.at](https://superspl.at)にサインインしていると、誰かがあなたのスプラットにコメントしたり、いいねしたり、あなたをフォローしたりしたときに知らせてくれます。このアクティビティは**Notifications**パネルで確認でき、メールで受け取ることもできます。

## 通知パネル

トップバーのベルをクリックするとパネルが開きます。まだ見ていないアクティビティがあると、ベルにそれが示されます。

パネルでは、アクティビティが内容ごとにまとめられています：

| アクティビティ | 表示内容 |
|----------|----------|
| **コメント** | 誰がどのスプラットにコメントしたか。コメントの抜粋も表示されます。 |
| **いいね** | 誰がどのスプラットにいいねしたか。同じスプラットに複数の人がいいねすると、たとえば**Alex and 3 others liked**のようにまとめられ、全員の一覧を開けます。 |
| **新しいフォロワー** | 誰があなたをフォローし始めたか。複数の人がフォローすると、同じようにまとめられます。 |

新しいアクティビティは強調表示されます。各項目にはその人のアバターと経過時間が表示され、スプラットへのアクティビティにはそのサムネイルが表示されます。サムネイルをクリックするとスプラットが開きます。スクロールすると、さらにアクティビティが読み込まれます。まだ何も起きていない間は、パネルに**Your community starts here**と表示されます。

パネル上部の歯車ボタンを押すと、[通知設定](#notification-settings)が開きます。

## 通知設定 {#notification-settings}

[superspl.at/settings/notifications](https://superspl.at/settings/notifications)の**Notification settings**ページでは、メールで受け取るアクティビティを選びます。通知パネルの歯車か、アカウントメニューの**Notification settings**から開けます。

<img loading="lazy" alt="3つのEmailスイッチがあるNotification settingsページ" width="680" src="/img/user-manual/supersplat/viewing/notification-settings.webp" />

**Email**の下には、アクティビティの種類ごとにスイッチがあります：

| スイッチ | メールが届くタイミング |
|--------|---------------------|
| **Comments** | コメントから数分以内。複数届いた場合はまとめられます。 |
| **Likes** | 毎日のまとめメールで。 |
| **New followers** | 毎日のまとめメールで。 |

スイッチを切り替えると、変更はすぐに保存されます。保存できなかった場合は、スイッチが元に戻り、ページにその旨が表示されます。

これらのスイッチが影響するのはメールだけです。通知パネルには、常に3種類すべてのアクティビティが表示されます。
