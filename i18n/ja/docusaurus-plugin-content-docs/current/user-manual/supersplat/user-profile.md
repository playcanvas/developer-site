SuperSplatの各クリエイターには`https://superspl.at/user/<username>`に公開プロファイルが用意されます。プロファイルには、アバター、表示名、自己紹介、追加されたソーシャルリンク、フォロワー数とフォロー中の数、そして公開したすべての**Public**スプラットのグリッドが表示されます。

プロファイルは、すべての[シーンページ](/user-manual/supersplat/scene-page)と[Explore](/user-manual/supersplat/explore)グリッドのすべてのカードに表示される**著者チップ**からリンクされます — 著者名をクリックするとプロファイルへ移動します。

プロファイルの閲覧は匿名で可能で、PlayCanvasアカウントは不要です。

![クリエイターのSuperSplatプロフィールページ — アバター、表示名、ソーシャルリンク、公開スプラットのグリッド](/img/user-manual/supersplat/user-profile.webp)

## 表示される内容

| セクション | 含まれるもの |
|---------|------------------|
| **アバターと表示名** | クリエイターのPlayCanvasアカウントのアバターと、選択した表示名。 |
| **自己紹介** | クリエイター自身が書いた短いプロフィール紹介。 |
| **ソーシャルリンク** | クリエイターが追加した外部プロフィール（X、LinkedIn、個人サイトなど）へのリンク。 |
| **フォロワーとフォロー中** | クリエイターをフォローしている人数と、クリエイターがフォローしている人数。どちらかの数をクリックすると、誰なのかが表示されます。 |
| **Follow** | クリエイターをフォローすると、そのスプラットが[Followingフィード](/user-manual/supersplat/following)に表示されます。 |
| **スプラットグリッド** | クリエイターが公開したすべての**Public**スプラットを、[Explore](/user-manual/supersplat/explore)と同じカードUIで表示。任意のカードをクリックすると、その[シーンページ](/user-manual/supersplat/scene-page)が開きます。 |

Unlistedのスプラットは公開プロファイルには表示されません — クリエイター本人だけが[Manageページ](/user-manual/supersplat/manage)から確認できます。

## 自分のプロファイル

自分のプロファイルには、次のものもあります。

- **フォローしている全員。** 自分の**following**の数をクリックするとリストが開き、誰でも[フォローを解除](/user-manual/supersplat/following#managing)できます。
- **Likesタブ。** いいねしたすべてのスプラットが表示されます。このタブはあなただけに表示されます。
