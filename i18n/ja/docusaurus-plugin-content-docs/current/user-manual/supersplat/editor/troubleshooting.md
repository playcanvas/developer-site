## Editorが起動しない

EditorにはWebGPUが必要です。読み込まれる代わりに「SuperSplat requires WebGPU, which this browser does not support」と表示される場合は、最新のChromeまたはEdge、Safari 26以降、あるいはWebGPUを有効にしたFirefoxに切り替え、ブラウザの設定でハードウェアアクセラレーションが有効になっていることを確認してください。複数のGPUを搭載したマシンでは、ブラウザが専用GPUを使用できるようにする必要があります。

「SuperSplat failed to start」と表示される場合は、ブラウザのコンソールで詳細を確認し、[問題を報告](#reporting-a-problem)する際にその内容を含めてください。

## ファイルをインポートできない

- [インポートとエクスポート](import-export.md)に記載された形式であることを確認します。メッシュまたは点群データだけを含む一般的な（「vanilla」）PLYは読み込めません。SuperSplatには、位置（`x`、`y`、`z`）、スケール（`scale_*`）、回転（`rot_*`）、不透明度、球面調和関数による色（`f_dc_*`、および任意の`f_rest_*`）などのGaussian属性を含む3DGS PLYが必要です。[3DGS PLYと通常のPLYの違い](/user-manual/gaussian-splatting/formats/ply)も参照してください。
- 複数の関連ファイルで構成される形式の場合、相対ファイルパスを維持できるように親フォルダをEditorへドラッグします。
- URLからインポートする場合、リモートサーバーでCross-Origin Resource Sharing（CORS）によるブラウザからの取得を許可する必要があります。
- ブラウザでメモリ不足が報告される場合は、詳細度の低いソースファイルを試し、GPUを多用するほかのタブを閉じ、スプラットを個別にインポートします。

## 選択範囲が表示サーフェスと一致しない

下ツールバー左側の2つのトグルを確認します。

- **Selection Depth**（`N`）はデフォルトでオフです。そのため選択はシーン全体を貫通し、クリックしたサーフェスの背後に隠れたガウシアンも対象になります。可視サーフェスだけを選択するにはオンにします。
- **Selection Footprint**（`M`）はデフォルトでオフです。そのため、中心点がツールの形状の内側にあるガウシアンだけが対象になります。中心点が選択範囲のすぐ外側にある大きくて柔らかいガウシアンは含まれません。フットプリント全体で選択するにはオンにします。

`Tab`は中心点とリングのオーバーレイの表示・非表示を切り替えるだけで、選択の動作は変わりません。ロックまたは削除されたガウシアンは選択できません。必要に応じて**Select > Unlock**または**Select > Reset**を使用してください。

[Selection DepthとSelection Footprint](editing-splats.md#selection-depth-and-footprint)と、[選択とクリーンアップ](editing-splats.md)のクリーンアップ手順を参照してください。

## 意図しない内容が変形される

ガウシアンが1つでも選択されている場合、Move、Rotate、Scale、およびTransformの数値はその選択範囲だけに作用します。アクティブスプラット全体を変形するには、**Select > None**を選択します。

回転や拡大縮小が想定外の点を中心に動く場合は、原点コントロールを切り替えるか、表示サーフェスをダブルクリックしてピボットを配置します。[変形、測定、位置合わせ](transform-measure-align.md)も参照してください。

## エクスポートにコンテンツが含まれない

スプラットのエクスポートには表示中のスプラットが含まれます。Scene Managerで、含めるすべてのスプラットの目のアイコンを有効にします。エクスポート前にSoloモードを無効にし、全体の結果を確認してください。

複数のスプラットを1つのPLYに結合するには、**File > Export > PLY**を使用します。**File > Save**では、編集可能な`.ssproj`プロジェクトが作成されます。

## 色の見え方が異なる

- **Preferences**でトーンマッピングカーブとビューポートに表示する球面調和関数バンド数を、**Appearance**で背景色を確認します。これらは表示設定であり、エクスポートには書き込まれません。
- Scene Managerの**Colors**を展開して**Reset**をクリックし、スプラットまたは選択範囲に適用されたカラーグレードが原因か確認します。
- 球面調和関数の色は視線方向に依存するため、複数のアングルからシーンを確認します。

スプラット調整とビューポート設定の違いについては、[色と外観](color-and-appearance.md)を参照してください。

## Editorが遅い、またはメモリ不足になる

大きなスプラットは、使用可能なGPUメモリによって制限されます。グラフィックスを多用するほかのタブを閉じ、Soloモードで一度に1つのスプラットだけを表示し、マルチLODファイルのインポート時には低い詳細度を選択します。スプラットをクリーンアップしてガウシアン数を減らすこともできます。大きなシーケンスをインポートする場合、各フレームに完全なスプラットが含まれることにも注意してください。

重いシーンを回転させている間にビューポートがカクつく場合は、**Preferences**を開いて**Stochastic Alpha**を確認します。**Auto**（デフォルト）は、ソート済みフレームが遅いと判明したときだけ、移動中に高速な確率的描画へ切り替えます。**Movement**を選ぶとカメラを動かすたびに使用し、**Enabled**を選ぶと常に使用します。[Overlays](interface.md#overlays)ポップアップの**Frame Timings**と**Overdraw**の診断機能で、時間がどこに使われているかがわかります。GPU時間が長く、オーバードローマップが赤から白の場合は多くのガウシアンが重なっているため、クリーンアップや詳細度の引き下げで改善できます。

## 未保存の作業またはプロジェクトに関する混乱

編集可能な`.ssproj`プロジェクトを保持するため、**File > Save**または**Save As**を定期的に使用します。スプラット配置、カメラ設定、アニメーションの編集を続ける場合、エクスポートしたPLYなどの配布形式はプロジェクトファイルの代わりにはなりません。

保存、開く、インポート、エクスポートの違いについては、[プロジェクトの管理](managing-projects.md)を参照してください。

## 公開またはレンダリングに失敗する

- 公開するには、PlayCanvasアカウントでsuperspl.atにサインインする必要があります。
- 動画コーデックの対応状況はブラウザによって異なります。Render Videoダイアログでは、現在の設定でブラウザやデバイスがエンコードできない解像度は無効になります。解像度、フレームレート、ビットレートを下げるか、別の形式やコーデックを試すか、ブラウザやグラフィックスドライバーを更新してください。
- ダウンロードのブロック、プライベートブラウジングの制限、空きメモリ不足によって、大きなレンダリングやエクスポートが完了しないことがあります。File System Access APIに対応していないブラウザでは、レンダリングとエクスポートはダウンロードとして提供されます。

## 問題の報告 {#reporting-a-problem}

問題が解決しない場合は、Editorで**Help > Log an Issue**を開き、ブラウザのバージョン、OS、ソース形式、おおよそのガウシアン数、問題を再現する手順を記載してください。[SuperSplat Discordコミュニティ](https://discord.gg/T3pnhRTTAY)で質問することもできます。
