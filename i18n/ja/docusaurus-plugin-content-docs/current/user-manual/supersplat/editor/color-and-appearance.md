SuperSplatでスプラットの見え方に影響するコントロールは2種類あります。

- Scene Managerの**Colors**セクションは、スプラットデータ自体を変更します：色合い、色温度、彩度、明るさ、階調範囲、透明度です。これらの編集はスプラットとともに保存・エクスポートされます。
- [モードストリップ](interface.md#mode-strip)と[Preferences](interface.md#preferences)のビューポートの色は、ビューポートがマーカーと選択範囲をどのように描画するかだけを変更します。スプラットは一切変更しません。

## Colors {#colors}

[Scene Manager](scene-management.md)の最下部、**Transform**の下にある**Colors**セクションを、ヘッダーをクリックして展開します。スライダーは保留中のカラーグレードを保持し、対象となるガウシアン（現在の選択範囲、または何も選択していない場合はアクティブスプラット全体）にビューポートでリアルタイムにプレビューされます。**Apply**をクリックすると、グレードがそれらのガウシアンにベイクされ、スライダーは次の調整に備えてニュートラルに戻ります。一部の領域だけを異なる設定でグレーディングするには、先にその領域を選択します。

### コントロール

| コントロール | 範囲 | 効果 |
|---|---|---|
| **Tint** | 色 | 色に選択した色合いを乗算します。白では元の色が変わりません。 |
| **Temperature** | −0.5～0.5 | 結果を寒色（負）または暖色（正）方向へ移動します。 |
| **Saturation** | 0～2 | 色の強さを下げたり上げたりします。`1`では彩度が変わりません。 |
| **Brightness** | −1～1 | 暗くまたは明るくします。`0`では明るさが変わりません。 |
| **Black Point** | 0～1 | 黒としてマッピングされる最暗値を上げ、シャドウのクリッピングを強めます。 |
| **White Point** | 0～1 | 白としてマッピングされる最明値を下げ、ハイライトのクリッピングを強めます。 |
| **Transparency** | −6～6 | 元の値に対して不透明度を下げたり（負）上げたり（正）します。 |

Black Pointは常にWhite Pointより下に保たれます。一方を動かしてもう一方にぶつかると、もう一方も押されて一緒に動きます。**Reset**は対象のガウシアンにすでに適用されているグレードを取り除き、スライダーをニュートラルに戻します。選択範囲を変更すると、未適用の保留中グレードは破棄されます。ApplyとResetは編集履歴に記録され、元に戻したりやり直したりできます。

### 実用的な色補正ワークフロー

1. 意図した表示条件でシーンを確認できるように、[Preferences](interface.md#preferences)でビューポートのトーンマッピングと背景色を設定します。
2. **Temperature**で全体の寒暖を補正します。
3. **Brightness**を調整し、次に**Black Point**と**White Point**で階調範囲を設定します。
4. **Saturation**と**Tint**で最終的なカラーバランスを整えます。
5. 複数のカメラアングルから結果を確認します。球面調和関数の色は視線方向によって変化する場合があります。
6. **Apply**をクリックします。

トーンマッピングと背景色は表示設定です。Colorsセクションはスプラット自体を変更します。

### グレードのコピーと貼り付け

**Colors**ヘッダーを右クリックして**Copy**を選ぶとすべてのスライダーの値を、1つの行を右クリックするとその値だけをコピーできます。値は`{"tint":[1,1,1],"temperature":0.1,"saturation":1.2,"brightness":0,"blackPoint":0,"whitePoint":1,"transparency":0}`のようなプレーンなJSONテキストとしてコピーされるため、メモに残しておいたり、別のEditorセッションに貼り付けたりできます。ヘッダーの**Paste**はこれらのキーの一部だけでも受け付けるため、`{"saturation":1.2}`を貼り付けると彩度だけが変わります。行の**Paste**は、単独の値またはコピーしたセクションを受け付けます。**Tint**には`#ffcc88`のような16進数のカラーコードも使用できます。貼り付けた値は各スライダーの範囲にクランプされます。クリップボードの内容が無効な場合は何も変更されず、対象が一瞬赤く点滅します。

コピーと貼り付けは、スライダーに表示されている保留中のグレードに対して行われます。貼り付けた後に**Apply**をクリックして、グレードをベイクしてください。

### 保存とエクスポート時の動作

適用済みのグレードはスプラットの色データの一部になるため、`.ssproj`プロジェクトに保存され、すべてのエクスポート形式に含まれます。保存やエクスポートの前に**Apply**をクリックしてください。適用していない保留中のグレードはプレビューにすぎません。

## マーカーと選択範囲の表示 {#appearance}

ビューポートでのマーカーと選択範囲の描画方法は、ビューキューブの横にある[モードストリップ](interface.md#mode-strip)で設定します。これらの設定は環境設定とともに保存され、ビューポートにだけ影響します。モードとX-Rayによって選択ツールの対象がどう変わるかは、[選択モードとX-Ray](editing-splats.md#selection-mode-and-x-ray)を参照してください。

### モードのオプション

モードストリップの**Centers**または**Rings**を長押しすると、そのオプションが開きます。短く押した場合は、モードが選択されるだけです。

| モード | コントロール | デフォルト | 説明 |
|---|---|---|---|
| Centers | **Center Size** | 2 | 中心点の大きさ（ピクセル、0～10）。 |
| | **Splat Colors** | オフ | 未選択の中心点を、未選択色ではなくそれぞれのガウシアンの色で描画します。 |
| Rings | **Ring Thickness** | 4 | リングの輪郭の太さ（1～50）。 |
| | **Splat Colors** | オン | 未選択のリングを、未選択色ではなくそれぞれのガウシアンの色で描画します。 |

選択されたマーカーは常に選択色を使用します。

### Markersのオプション

モードストリップの**Markers**を長押しすると、そのオプションが開きます。短く押すと、<kbd>Tab</kbd>と同じようにマーカーの表示を切り替えます。

| コントロール | デフォルト | 説明 |
|---|---|---|
| **Markers Only** | オフ | マーカーを表示している間はガウシアン自体を非表示にし、点またはリングだけを残します。 |
| **Tint Selection** | オフ | 選択されたガウシアンを選択色で着色します。 |
| **Outline Selection** | オフ | 選択範囲のシルエットの周囲に、選択色でアウトラインを描画します。 |

### ビューポートの色

**Background Color**、**Selected Color**、**Unselected Color**、**Locked Color**は、[Preferences](interface.md#preferences)ポップアップの**Colors**セクションで設定します。これらの色は、マーカー、選択範囲の着色とアウトライン、[Splat Data](data-panel.md)ヒストグラムで使用されます。

色などの属性をガウシアン単位で確認および選択するには、[Splat Dataパネル](data-panel.md)を使用します。スプラットの外観を整えた後でビューポートカメラをアニメーション化するには、[Timeline](timeline.md)を参照してください。
