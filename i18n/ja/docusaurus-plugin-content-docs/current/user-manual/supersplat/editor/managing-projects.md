SuperSplatは、すべての設定とアニメーションを保持しながら作業を保存および再ロードできる`.ssproj`ファイル形式をサポートしています。この形式は、プロジェクトを管理し、作業を共有し、後で編集を続けるための効率的な方法を提供します。

## `.ssproj`ファイルの機能

* フルプロジェクト保存: インポートしたすべてのスプラットを、その編集内容、変形、ピボット、適用済みのカラーグレードとともに保存します。さらに、カメラ、グリッド平面や[Anti-Aliasing](interface.md#preferences)設定などの表示設定、タイムラインアニメーションも保存されます。
* 簡単な再ロード: 保存されたプロジェクトファイルをロードして、作業の正確な状態を復元します。
* 移植性: 他のユーザーと`.ssproj`ファイルを共有して、プロジェクトで共同作業を行います。

## プロジェクトの保存

現在の作業を`.ssproj`ファイルとして保存するには：

* `File`メニューを開き、`Save As`を選択します。
* **Save As**ダイアログの**Location**で出力フォルダーを選択します。Editorは最後に使用したフォルダーを記憶しています。別のフォルダーを選ぶには**Choose output folder…**（または**Change…**）をクリックします。
* **Filename**を入力します。同名のファイルがすでに存在する場合は警告が表示され、**Overwrite**で上書きできます。
* **Save**をクリックします。プロジェクトは`.ssproj`ファイルとして保存されます。

プロジェクトに名前が付くと、`File` > `Save`は確認なしに同じファイルへ再度書き込みます。File System Access APIに対応していないブラウザでは、プロジェクトはダウンロードとして提供されます。

## プロジェクトのロード

以前に保存した`.ssproj`ファイルをロードするには：

* `File`メニューを開いて`Open`を選択し、`.ssproj`ファイルを参照して`Open`をクリックします。
* または、`File` > `Open Recent`から、以前に開いたり保存したりしたプロジェクトを選択します。
* または、`.ssproj`ファイルをEditorのウィンドウにドラッグします。
* SuperSplatをアプリとしてインストールしている場合は、File Explorer（Windows）またはFinder（macOS）で`.ssproj`ファイルをダブルクリックします。

SuperSplatはプロジェクトを最後に保存された状態に復元します。

選択したファイルの読み取りをブラウザがブロックした場合、SuperSplatは**File Access Blocked**メッセージを表示します。**OK**をクリックし、ブラウザのファイルダイアログでもう一度ファイルを選択してください。この方法で開いたプロジェクトは名前を保持しますが、File System Access APIに対応していないブラウザと同様に、**Save**を選ぶと保存先を尋ねられます。

## ファイル構造

`.ssproj`形式は、実際には次の内容を含むZIPアーカイブです。

* プロジェクトのメタデータ（カメラ、表示設定、カメラポーズ、タイムライン、スプラットの一覧）を保存するJSONドキュメント。
* スプラットデータ。非圧縮の`.ply`ファイルとして1回だけ保存され、各スプラットの編集状態（選択、ロックおよび削除されたガウシアン、変形、カラーグレード）を保持する小さなスプラット単位のファイルが付属します。ロード時には各スプラットがScene Managerの行として表示されます。
