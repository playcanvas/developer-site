PlayCanvas Engineは[セマンティックバージョニング](https://semver.org/lang/ja/)に従っています。各リリースのバージョン番号は、`2.23.3`のような`major.minor.patch`の形式です。

:::important

まれに、マイナーリリースに破壊的な変更が含まれたことがあります。たとえば2.5.0では、`ShaderMaterial`によるガンマ補正、トーンマッピング、フォグの処理が変更されました。私たちはこうした変更を避けるよう最大限努めており、そのような変更はすべて[エンジンマイグレーション](migrations.md)に記載しています。

:::

## 受け入れる更新を選択する {#choosing-which-updates-to-accept}

`npm install playcanvas`を実行すると、npmは`package.json`にEngineを`"playcanvas": "^2.23.3"`のようなキャレット（`^`）範囲で記録します。キャレット範囲はそれ以降のすべての2.xリリースを受け入れるため、依存関係を更新すると新しいマイナーバージョンに移行する場合があります。受け入れる更新を絞り込むには、別の範囲を指定してインストールします。

| 受け入れる更新 | コマンド | `package.json`の記述 |
| --- | --- | --- |
| マイナーリリースとパッチリリース（npmのデフォルト） | `npm install playcanvas` | `"^2.23.3"` |
| パッチリリースのみ | `npm install playcanvas@~2.23.3` | `"~2.23.3"` |
| なし（1つのバージョンに固定） | `npm install playcanvas --save-exact` | `"2.23.3"` |

範囲は、`npm update`で移行できるバージョンと、ロックファイルがない状態で新しくインストールしたときに解決されるバージョンを決めます。インストール済みの正確なバージョンは引き続き`package-lock.json`に記録され、`npm ci`はそのバージョンをインストールします。これらの範囲がベータ版、プレビュー版、アルファ版のビルドを選択することはないため、それらは[タグを指定](#npm-tags)した場合にのみインストールされます。

代わりにCDNからEngineを読み込む場合は、`https://cdn.jsdelivr.net/npm/playcanvas@2.23.3/+esm`のようにURLにバージョンを含めます。バージョンを含まないURLは、常に最新のリリースを読み込みます。

## リリースの種類 {#release-types}

| リリース | 例 | 内容 |
| --- | --- | --- |
| パッチ | 2.23.2 → 2.23.3 | バグ修正のみ。APIは変更されません。 |
| マイナー | 2.22.6 → 2.23.0 | 新機能。既存のAPIが非推奨になる場合があります。非推奨のAPIは引き続き動作し、使用するとデバッグ版Engineが警告をログに出力します。 |
| メジャー | 1.x → 2.0.0 | 大規模なAPIの変更。Engine v2では、WebGL 1のサポートとレガシーなスクリプトシステムが、多くの非推奨APIとともに削除されました。 |

## npmタグ {#npm-tags}

Engineは安定版リリースに加えて、プレリリースビルドもnpmに公開しています。ビルドの種類ごとに専用のタグがあります。

| タグ | バージョン形式 | 内容 |
| --- | --- | --- |
| `latest` | `X.Y.Z` | 現在の安定版リリース。`npm install playcanvas`はこれをインストールします。 |
| `beta` | `X.Y.0-beta.N` | 次のマイナーリリースに向けた`main`ブランチのビルド。前回のベータ版以降に`main`が変更されていれば、毎晩02:00（UTC）に作成されます。マージ済みで、まだリリーステストを経ていない機能が含まれます。 |
| `preview` | `X.Y.Z-preview.N` | マイナーリリースまたはパッチリリースを`release-X.Y`ブランチで準備しているときに、リリースが確定する前に公開されます。最近のリリースは数分以内に続けて公開されているため、このタグは`latest`より古いバージョンを指していることがよくあります。 |
| `alpha` | `X.Y.Z-alpha.PR.N` | マージ前に変更をテストするため（モバイルデバイスでのテストなど）に、プルリクエストから不定期に作成されるビルド。プロジェクトでは使用しないでください。 |
| `lts` | `1.Y.Z` | Engine v1の最新リリース。Engine v1は重要な修正のみを受け取ります。[エンジン互換性](../editor/engine-compatibility.md)を参照してください。 |

タグ付きのビルドをインストールするには、パッケージ名にタグを付けます。

```bash
npm install playcanvas@beta
```

各タグが現在どのバージョンを指しているかを確認するには、次を実行します。

```bash
npm view playcanvas dist-tags
```

## Editorプロジェクト {#editor-projects}

EditorプロジェクトはnpmからEngineをインストールしません。代わりに、プロジェクトの起動、公開、ダウンロードに使用するEngineのリリースを、Editorの[エンジン設定](../editor/interface/settings/engine.md)で選択します。
