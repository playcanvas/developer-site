**Organization**は、チームのための共有アカウントです。プロジェクトは1人のユーザーの個人アカウントの下に置かれるのではなくOrganizationに所属し、オーナーと任意の数の管理者がプロジェクト、メンバー、請求をまとめて管理します。Organizationは**Freeプラン**でも利用でき、必要に応じて有料プランにアップグレードできます。

## Organizationとは？

Organizationは、個人のログインではなく、チームが所有するワークスペースです。個人アカウントとは次の点で異なります。

- **特定の個人に紐付きません。** Organizationとして直接ログインすることはありません。代わりに、自分自身のユーザーアカウントを通じて、**オーナー**または**管理者**として管理します。
- **複数の管理者を持てます。** オーナーは任意の数の管理者を指定でき、管理者はOrganizationのプロジェクト、メンバー、請求を管理します。所有権の譲渡とOrganizationの削除ができるのはオーナーのみです。
- **プロジェクトはチームに帰属します。** プロジェクトは個人ではなくOrganizationが所有するため、特定のメンバーのアカウントに左右されません。
- **所有権を譲渡できます。** オーナーがチームを離れる場合でも、プロジェクトに影響を与えることなく、別のユーザーに所有権を引き継げます。

## Organizationと個人アカウントの比較

違いは、どのプランを利用しているかではなく、**誰がアカウントを所有・管理するか**にあります。Organizationは、個人アカウントと同じようにFreeプランでも利用できます。

| | 個人アカウント | Organization |
|---|---|---|
| 所有者 | 個人（あなた） | チームまたは企業 |
| 管理者 | 自分のみ | オーナーと任意の数の管理者 |
| プロジェクトとメンバー | プロジェクトごとに自分で共同作業者を管理 | 管理者がプロジェクトとメンバーを一元管理 |
| 適した対象 | 個人 | あらゆる規模のチーム |

## プラン

Organizationは**Freeプラン**で利用でき、上記の共有アカウントとチーム管理の機能に加えて、無制限の公開プロジェクトを利用できます。

チームが**プライベートプロジェクト**、より多くのストレージ、1枚の請求書にまとめられたシート単位の請求を必要とする場合は、有料の**Organizationプラン**にアップグレードします。シートは1つあたり月額50ドル（日本では税込9,900円）で、いつでも追加・削除でき、次回の請求日に日割りで精算されます。請求に関するFAQの[計算例](/user-manual/account-management/billing/#how-is-billing-for-organization-accounts-calculated)をご覧ください。[プランページ](/user-manual/account-management/plans-and-billing/#plans)では、すべてのプランを詳しく比較できます。

## Organizationを使用するタイミング

Organizationは、次のような場合に適しています。

- プロジェクトを個人のアカウントではなく、チームや企業に帰属させたい場合。
- プロジェクト、メンバー、権限を管理する管理者が複数人必要な場合。
- 他のメンバーと共同で作業し、共有のワークスペースが欲しい場合（Freeプランでも可能です）。
