すべてのPlayCanvasアカウントには公開プロフィールがあります。アドレスは次のとおりです。

```none
https://playcanvas.com/user/<USERNAME>
```

自分のプロフィールを開くには、[プロジェクトダッシュボード](/user-manual/editor/projects/dashboard/)のサイドバー下部にある自分の名前を選択し、**View public profile**を選びます。

![プロフィール](/img/user-manual/account-management/user-accounts/profile.webp)

プロフィールには次の内容が表示されます。

- プロフィール画像、氏名、ユーザー名
- PlayCanvasに参加した時期
- **Coder**や**Artist**などのスキル
- 公開プロジェクトの**views**、**plays**、**stars**の合計
- **Public projects**の一覧

一覧に表示されるのは公開プロジェクトのみのため、ログインしていない訪問者を含め、誰でもプロフィールを閲覧できます。自分のプロフィールを表示すると、これが他のユーザーから見た表示であることを示す注記が上部に表示されます。

## 公開プロジェクト {#public-projects}

公開プロジェクトは、名前、オーナー、説明で検索できます。また、`name:`など、[プロジェクトダッシュボード](/user-manual/editor/projects/dashboard/#finding-projects)と同じフィルターで一覧を絞り込むこともできます。**Sort by**では、プロジェクトを**Last edited**、**Last opened**、**Created**、**Name**、**Most viewed**、**Most played**、**Size**のいずれかで、**Descending**または**Ascending**に並べ替えます。その横のボタンで、カード表示とリスト表示を切り替えます。

## プロフィールの編集 {#editing-your-profile}

**Edit profile**を選択すると、新しいタブで[アカウント設定](settings.md)が開きます。そこでは、プロフィール画像、ユーザー名、氏名、スキルを変更したり、Webサイトやソーシャルアカウントへのリンクを追加したりできます。

:::tip

ログインすると、[playcanvas.com](https://playcanvas.com)から[プロジェクトダッシュボード](/user-manual/editor/projects/dashboard/)に移動します。プロジェクトダッシュボードには、公開・プライベートを問わず、すべてのプロジェクトが一覧表示されます。

:::
