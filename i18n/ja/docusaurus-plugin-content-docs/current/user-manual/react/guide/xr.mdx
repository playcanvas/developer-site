PlayCanvas React を使えば、WebXR API を利用した Virtual Reality (VR) と Augmented Reality (AR) のサポートをアプリケーションに簡単に追加できます。

## 基本セットアップ

React アプリケーションで XR サポートを有効にするには、以下が必要です:

1. **XR Script** - PlayCanvas エンジンパッケージから XR コントローラーとナビゲーション Script をインポートする
2. **カメラ設定** - XR Script をアタッチしたカメラ Entity を設定する
3. **XR コントロール** - XR セッションの開始と終了のための UI ボタンを追加する（WebXR にはユーザーインタラクションが必要）
4. **セキュアコンテキスト** - HTTPS 経由でアプリを配信する（開発中は `localhost` でも可）

## XR Script

PlayCanvas エンジンは、よくある作業のための XR Script を提供しています。このガイドでは 3 つを使用します:

- **`XrSession`** - アプリイベントに応じてセッションを開始・終了し、カメラリグを配置し、AR ではカメラを透過させる
- **`XrControllers`** - 検出されたコントローラー（ハンドトラッキングを含む）の XR コントローラーモデルを自動的にダウンロードしてレンダリングする
- **`XrNavigation`** - ポイントアンドセレクトアクションを使用したテレポーテーションベースのナビゲーションを実装する

PlayCanvas Script パッケージからインポートします:

```tsx
import { XrSession } from 'playcanvas/scripts/esm/xr/xr-session.mjs'
import { XrControllers } from 'playcanvas/scripts/esm/xr/xr-controllers.mjs'
import { XrNavigation } from 'playcanvas/scripts/esm/xr/xr-navigation.mjs'
```

## カメラ設定

XR を正しく動作させるには、XR Script をアタッチしたカメラ Entity が必要です。推奨される構造は以下の通りです:

```tsx
<Entity name="camera-root">
  <Entity name="camera" position={[0, 1.6, 0]}>
    <Camera clearColor="#1e1e1e" />
  </Entity>
  <Script script={XrSession} />
  <Script script={XrControllers} />
  <Script script={XrNavigation} />
</Entity>
```

カメラはおよそ目の高さ（1.6 メートル）に配置され、Script は親 Entity、つまりカメラリグにアタッチされています。セッション中はヘッドセットがリグの中でカメラを動かし、リグを動かすとユーザーが移動します。[セッション](/user-manual/xr/sessions/#the-camera-and-its-rig)を参照してください。

## XR セッションの開始

WebXR ではセッションを開始するためにユーザージェスチャーが必要です。カメラリグに `XrSession` がある場合は、クリックハンドラーからそのイベントを発火します。`XrSession` はリグ内のカメラでセッションを開始し、`xr:end` または Escape キーで終了します:

```tsx
const app = useApp()

const startVR = () => app.fire('vr:start')
const startAR = () => app.fire('ar:start')
const endXR = () => app.fire('xr:end')
```

平面検出などの機能をリクエストするには、`camera.startXr()` でカメラのセッションを自分で開始します。[セッション](/user-manual/xr/sessions/#session-features)を参照してください。

- **Escape** キーでアクティブな XR セッションを終了できます

- フル体験をテストするには VR ヘッドセットまたは AR 対応モバイルデバイスを使用してください
- 開発中は、[Immersive Web Emulator](/user-manual/xr/testing/#without-a-headset) 拡張機能で Chrome と Edge にヘッドセットをエミュレートできます

:::

## XR の利用可能性チェック

現在のデバイスで AR または VR が利用可能かどうかを確認できます。エンジンはアプリケーションの起動後と、デバイスが変化したときに確認するため、結果をステートに保持し、`available` イベントに従ってください:

```tsx
const app = useApp()
const [vrAvailable, setVrAvailable] = useState(false)

useEffect(() => {
  const update = () => setVrAvailable(app.xr.isAvailable('immersive-vr'))
  update()
  const handle = app.xr.on('available', update)
  return () => handle.off()
}, [app])
```

## XR イベント

XR セッションイベントをリッスンして UI を更新します:

```tsx
useEffect(() => {
  const onStart = () => console.log('XR session started')
  const onEnd = () => console.log('XR session ended')
  
  app.xr.on('start', onStart)
  app.xr.on('end', onEnd)
  
  return () => {
    app.xr.off('start', onStart)
    app.xr.off('end', onEnd)
  }
}, [app])
```
