# `<Anim/>`

`Anim` コンポーネントは、[Entity](../entity) のアニメーション再生を有効にします。アニメーション Asset からアニメーションクリップを再生し、その再生を制御できます。

## 使い方

```jsx copy
import { Entity } from '@playcanvas/react'
import { Anim, Render } from '@playcanvas/react/components'
import { useModel } from '@playcanvas/react/hooks'

const AnimatingDinosaur = (props) => {
  const { asset } = useModel('/dinosaur.glb')

  if (!asset) return null

  return (
    <Entity {...props}>
      <Render type="asset" asset={asset} />
      <Anim asset={asset} playing />
    </Entity>
  )
}
```

Asset を指定すると、`<Anim>` はそのアニメーションをすべて 1 つのステートに入れるため、アニメーションが複数ある場合は最後のものだけが再生されます。クリップを名前で再生する方法や、ステートグラフ、レイヤー、イベントの使い方は、[アニメーション](/user-manual/animation/)セクションを参照してください。

`playing` は必ず指定してください。`<Anim>` はレンダリングされるたびにすべての props をエンジンのコンポーネントに設定し、`playing` のデフォルトは `false` です。指定しないと、コンポーネントが再びレンダリングされた時点でアニメーションが止まります。

PlayCanvas ドキュメントの [Anim Component](https://api.playcanvas.com/engine/classes/AnimComponent.html) で詳細を確認できます。

## プロパティ

```tsx asTypedoc
import { Anim } from '@playcanvas/react/components'
type $ = React.ComponentProps<typeof Anim>;
export default $;
```
