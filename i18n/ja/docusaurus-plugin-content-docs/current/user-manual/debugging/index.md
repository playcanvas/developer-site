デバッグは、PlayCanvasアプリケーションの問題を、スクリプトだけでなくレンダリングやロードされるものも含めて特定し、修正するために不可欠です。期待通りに動作しない場合、これらのツールとテクニックは問題を迅速に見つけて解決するのに役立ちます。動作が遅い理由を調べるには、[使うツール](/user-manual/optimization/#which-tool-to-use)を参照してください。

## デバッグテクニック

### コンソールロギング

コードが何をしているかを理解する最も手軽な方法です。実行フローを追跡し、変数の値を検査するために`console.log()`ステートメントを追加します。

**[コンソールロギングを学ぶ →](./console-logging.md)**

### ブラウザ開発者ツール

ブレークポイント、ステップスルーデバッグ、パフォーマンスプロファイリングを使用して、実行中のコードを詳細に検査します。

**[ブラウザ開発者ツールを学ぶ →](./browser-dev-tools.md)**

### Inspector

実行中のアプリケーションの内部を確認します。エンティティとコンポーネント、カメラ、アセット、GPUリソース、各フレームのパス、そしてパスの描画を1つずつ確認できます。

**[Inspectorを学ぶ →](./inspector.md)**

### デバッグ描画

シーンの上に線、形状、テクスチャを描画して、バウンディングや方向、レンダーターゲットの内容やシーンの深度など、コードが計算するものを確認します。

**[デバッグ描画を学ぶ →](/user-manual/graphics/debug-drawing/)**
