発生している問題を見つけ、その原因を上から順に確認してください。

## セッションの開始 {#starting-a-session}

| 問題 | 原因 | 解決方法 |
| --- | --- | --- |
| VRやARが利用可能にならず、XRを開始するボタンが表示されない | ページがセキュアコンテキストにない | HTTPSで配信するか、`localhost`から配信します。[デバイスでのテスト](/user-manual/xr/testing/#testing-on-a-device)を参照してください |
| | XRを許可していないiframeの中にページがある | `<iframe>`に`allow="xr-spatial-tracking"`を追加します。デバッグビルドでは、この理由で利用可能かどうかの確認をスキップすると、エンジンが警告をログに出力します |
| | グラフィックスデバイスがWebGPUを使用しているが、ブラウザがWebGPUをヘッドセットに表示できない | WebGL 2を使用します。[グラフィックスデバイスの選択](/user-manual/xr/using-webxr/#choosing-a-graphics-device)を参照してください |
| | デバイスがそのセッションタイプをサポートしていない（Apple Vision ProでのARなど） | [プラットフォーム](/user-manual/xr/platforms/)を参照してください |
| | アプリケーションの開始時に、コードが`isAvailable`を一度だけ確認している | 結果は非同期で届きます。`available`イベントをリッスンしてください。[利用可能かどうかの確認](/user-manual/xr/sessions/#checking-availability)を参照してください |
| | アプリケーションにXRマネージャーがないため、`app.xr`が`null`になっている | `AppBase`で作成したアプリケーションの`AppOptions`に、`options.xr = XrManager`を追加します |
| ボタンを選択してもセッションが開始しない | `await`の後やタイマーからなど、ユーザー操作のハンドラーの外でセッションを要求している | `startXr`の呼び出し、またはセッションを開始するイベントの発火を、クリックハンドラーの中で直接行います |
| | `bounded-floor`など、デバイスがサポートしていない参照空間を要求している | まずは`local-floor`を使います。エラーを確認するには、`startXr`にコールバックを渡します。[参照空間](/user-manual/xr/sessions/#reference-spaces)を参照してください |
| | セッションがすでに実行中か、開始処理中である | 一度に実行できるセッションは1つだけです。コールバックには`XR session is already started`または`XR session is already starting`が渡されます |
| セッション中に平面検出などの機能が利用できない | その機能を要求するオプションを指定せずにセッションを開始している | `startXr`にそのオプションを渡します。`XrSession`スクリプトは、オプションを指定せずにセッションを開始します。[オプションと機能](/user-manual/xr/sessions/#options-and-features)を参照してください |
| | デバイスまたはユーザーがその機能を許可していない | `app.xr.session.enabledFeatures`を確認し、[プラットフォーム](/user-manual/xr/platforms/)を参照してください |

## セッション中 {#in-the-session}

| 問題 | 原因 | 解決方法 |
| --- | --- | --- |
| カメラの位置や回転を設定しても効果がない | ヘッドセットが毎フレーム、カメラのローカルの位置と回転を設定している | カメラの親であるリグを動かします。[カメラとそのリグ](/user-manual/xr/sessions/#the-camera-and-its-rig)を参照してください |
| ユーザーの位置が高すぎる、低すぎる、または床の中にいる | セッションが`local`空間を使用していて、その原点がユーザーの頭の位置にある | 原点が床にある`local-floor`を使用します |
| | リグがシーンの床の上にない | リグを床の高さに置きます。`XrSession`スクリプトは、セッションの開始時にリグをy = 0に置きます |
| ユーザーの開始位置や向きが、ページで見ていたビューと異なる | `XrSession`スクリプトが、リグをカメラの真下に移動し、カメラと同じ方向に向けている | セッションの開始前に、ユーザーを開始させたい位置と向きにカメラを配置します |
| セッションの終了後、カメラが元の位置に戻らない | リグに`XrSession`スクリプトがない限り、何も元に戻さない | `XrSession`を追加するか、`start`と`end`のハンドラーで、カメラとリグを自分で保存して復元します |
| コントローラーや手が描画されない | 描画する処理がない（エンジンはそれらのポーズを報告するが、モデルは描画しない） | リグに`XrControllers`スクリプトを追加します。[はじめに](/user-manual/xr/using-webxr/#your-first-vr-scene)を参照してください |
| | `XrControllers`がモデルをダウンロードできない | モデルはCDNから読み込まれるため、デバイスにはインターネット接続が必要です。モデルを自分でホストするには、`basePath`属性を設定します |
| コントローラーが間違った位置に描画される | モデルがリグの子ではなく、ローカルのポーズで配置されている | ワールドの位置と回転（`getPosition()`と`getRotation()`）を使うか、モデルをリグの下に追加します。[トラッキング空間](/user-manual/xr/sessions/#tracking-space)を参照してください |
| 目に近づけるとオブジェクトが消える | カメラのニアクリップ距離が大きすぎる | `nearClip`を0.01〜0.1の範囲に設定します |
| セッションの終了後も、XRを開始するボタンが非表示のままになる | ボタンの`end`ハンドラーが`app.xr.active`を確認しているが、`end`ハンドラーの実行中はこの値がまだ`true`である | [はじめに](/user-manual/xr/using-webxr/#your-first-vr-scene)のように、`active`を確認せずに`end`ハンドラーでボタンを表示します。[セッションの終了](/user-manual/xr/sessions/#ending-a-session)を参照してください |
| システムメニューの裏でアプリケーションが動き続ける | セッションの表示状態の変化に反応していない | `visibility:change`イベントで一時停止します。[表示状態](/user-manual/xr/sessions/#visibility)を参照してください |

## ARの場合 {#in-ar}

| 問題 | 原因 | 解決方法 |
| --- | --- | --- |
| 背景が現実の世界ではなく、黒や単色になる | カメラが不透明な色でクリアされているか、スカイボックスが描画されている | カメラのクリアカラーを透明な`new Color(0, 0, 0, 0)`にし、スカイボックスのレイヤーを非表示にします。`XrSession`スクリプトは、ARセッション中にこの両方を行います |
| ヒットテストの結果、平面、アンカーに配置したコンテンツの位置がずれている、またはユーザーの移動に合わせてずれていく | これらのポーズはトラッキング空間のもので、リグがシーンの原点から移動している | コンテンツをリグの子として追加し、ローカルの位置と回転を設定します。[トラッキング空間](/user-manual/xr/sessions/#tracking-space)を参照してください |

## パフォーマンス {#performance}

| 問題 | 原因 | 解決方法 |
| --- | --- | --- |
| 表示がぼやける、またはテキストが読みにくい | セッションが、デバイスの推奨解像度より低い解像度で描画している | `maxPixelRatio`を`window.devicePixelRatio`に設定します。[解像度](/user-manual/xr/optimizing-webxr/#resolution)を参照してください |
| ユーザーが見回すと、表示がカクついたりぶれたりする | フレームの処理に、ヘッドセットのフレーム時間より長くかかっている | [パフォーマンス](/user-manual/xr/optimizing-webxr/)を参照し、[フレームレート](/user-manual/xr/optimizing-webxr/#frame-rate)または解像度を下げます |
| 固定フォービエーションが効かない | WebGLで、グラフィックスデバイスがアンチエイリアスを使用している | `antialias: false`を指定してデバイスを作成します。[固定フォービエーション](/user-manual/xr/optimizing-webxr/#fixed-foveation)を参照してください |
