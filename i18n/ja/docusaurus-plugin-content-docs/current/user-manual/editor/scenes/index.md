**シーン**はPlayCanvasアプリケーションの基盤です。ユーザーが体験する3Dワールドを定義し、ゲームやインタラクティブ体験を構成するすべてのエンティティ、コンポーネント、設定が含まれます。

## シーンの構成要素

すべてのシーンには以下が含まれます。

- **エンティティ** - シーン内のオブジェクトで、階層構造で整理されています。エンティティはキャラクター、小道具、ライト、カメラ、その他あらゆる要素を表すことができます。
- **コンポーネント** - エンティティに動作と外観を与える構成要素です。コンポーネントはレンダリング、物理、オーディオ、ユーザーインターフェースなどを処理します。
- **シーン設定** - シーン全体に影響するグローバルプロパティで、物理の重力、アンビエントライティング、フォグ、スカイボックスなどが含まれます。

## シーンのサイズ上限 {#size-limit}

PlayCanvasのサーバーは各シーンを1つのドキュメントとして保存しており、このドキュメントは16MBを超えられません。シーンがこの上限を超えることになる変更は保存されないため、シーンは上限より十分に小さく保ってください。

シーンに保存されるものはすべて上限に含まれます。

- **エンティティ** - すべてのエンティティと、そのすべてのコンポーネントおよびプロパティ値です。
- **スクリプト属性** - 各スクリプトに設定された値で、JSON（JavaScript Object Notation）属性や配列も含みます。
- **テンプレートのインスタンス** - 各インスタンスは、エンティティ階層の完全なコピーをシーン内に保存します。テンプレートを100回配置すると、その階層が100回保存されます。
- **シーン設定** - ごくわずかな容量しか使いません。

アセットは含まれません。モデル、テクスチャ、オーディオ、スクリプトなどのアセットは別に保存され、シーンはIDでそれらを参照するだけです。インポートしたモデルは、階層に追加するまでシーンのサイズを増やしません。追加するとモデルの各ノードがエンティティになり、それらのエンティティは上限に含まれます。

### サイズの警告

JSONとして14MBを超えるデータを持つシーンを開くと、Editorに「You are close to your scene size limit.」という赤いバナーが表示されます。保存されるサイズはJSONのサイズと完全には一致しないため、余裕を持たせて早めに警告が表示されます。警告が出たら、シーンを小さくし始める合図と考えてください。

Editorがサイズを確認するのは、シーンを読み込むときだけです。シーンを小さくしたら、Editorを再読み込みして確認し直してください。また、[エディターAPI](/user-manual/editor/editor-api/)を使い、ブラウザーの開発者コンソールで次のコードを実行すると、現在のシーンのサイズをいつでも測定できます。

```javascript
JSON.stringify(editor.api.globals.realtime.scenes.current.data).length;
```

結果は文字数です。この値が14,680,064（14 × 1024 × 1024）を超えると警告が表示されます。

### 上限内に収める方法

- **複数のシーンに分割する** - レベル、エリア、メニューごとにシーンを分けます。実行時にシーンを切り替えるか、複数のシーンを加算的に読み込んで大きなワールドを構成します。[シーンの読み込み](loading-scenes.md#シーンを加算的に読み込む)を参照してください。
- **実行時にテンプレートをインスタンス化する** - Editorで配置したテンプレートのインスタンスはシーンに保存されますが、スクリプトから生成するテンプレートはアセットに1回だけ保存されます。敵、アイテム、小道具など何度も登場するオブジェクトは、コードから生成します。[実行時にインスタンス化](/user-manual/editor/templates/#instantiating-at-runtime)を参照してください。
- **実行時にデータを読み込む** - レベルのレイアウト、会話、設定テーブルなどの大きなデータは、スクリプト属性ではなく[JSONアセット](/user-manual/editor/assets/inspectors/json/)に保存し、アプリケーションで必要になったときに読み込みます。[読み込みとアンロード](/user-manual/assets/loading-unloading/)を参照してください。
- **不要なものを削除する** - テスト用のオブジェクトや、インポートしたモデルの使わないノードなど、不要なエンティティを削除します。

:::ai
シーン内の反復的な変更には、AIアシスタントと[**Editor MCP Server**](/user-manual/editor/mcp-server/)で対象のエンティティとコンポーネントを特定し、一括編集を準備します。対象を確認し、ViewportとLauncherのキャプチャで不整合を探します。
:::
