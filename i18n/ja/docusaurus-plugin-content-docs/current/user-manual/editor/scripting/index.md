スクリプトは、エンティティに動きを与える方法です。Editorでは、スクリプトは他と同じアセットの一種です。Assetsパネルで作成し、Scriptコンポーネントでエンティティにアタッチし、コードに触れずにInspectorで属性を調整します。このセクションでは、そのためのEditorのツールを説明します。

:::tip[まず基本を学びましょう]

PlayCanvasでのスクリプト作成が初めての場合は、共通トピックの[スクリプティング](/user-manual/scripting/)から始めてください。スクリプトでできること、つまりライフサイクル、属性、イベント、スクリプトが扱うEngineについて説明しています。その内容はすべてEditorのプロジェクトのスクリプトにも当てはまります。

:::

Editorは2種類のスクリプトに対応しています。**ESMスクリプト**はECMAScriptモジュール（`.mjs`ファイル）で、互いに、またパッケージから`import`でき、新しいプロジェクトにはこちらをおすすめします。**クラシックスクリプト**（`.js`ファイル）は以前からある形式で、引き続き使えます。スクリプトを作成するときは、名前で種類が決まります。ESMスクリプトにするには名前を`.mjs`で終わらせてください。[ESMスクリプト](/user-manual/scripting/esm-scripts/)を参照してください。
