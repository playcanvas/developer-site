[初めてのアプリ](your-first-app.md)の次は、ここにあるチュートリアルで多くのプロジェクトに必要なことを学べます。チュートリアルは目的ごとにまとめてあり、各グループはそれより前のグループを土台にしているので、順番に進めるとEditorを無理なく身につけられます。作りたいものが決まっている場合は、それに合う目的へ直接進んでください。各グループの最後には、そのトピックを詳しく説明するマニュアルの章を挙げています。

## 1. コードで動かす {#control-things-with-code}

- [エンティティ操作](/tutorials/manipulating-entities/): スクリプトからエンティティを移動、回転、拡大縮小し、子が親についていく様子を確かめます。
- [キーボード入力の基礎](/tutorials/keyboard-input/): キーが押されたときや押し続けられているときに反応します。
- [基本的なマウス入力](/tutorials/mouse-input/): マウスの動きとボタンの押下を読み取ります。

さらに詳しく: [スクリプティング](/user-manual/scripting/)では、スクリプトのライフサイクル、属性、イベントを説明しています。

## 2. 画面を構成する {#frame-the-action}

- [カメラの基本操作](/tutorials/basic-cameras/): カメラを追加し、シーンが描画されるように設定します。
- [カメラのさらなる活用](/tutorials/more-cameras/): アプリの実行中に、スクリプトからカメラのズーム、移動、切り替えを行います。

さらに詳しく: [カメラ](/user-manual/graphics/cameras/)

## 3. ぶつけて動かす {#collide-and-push}

- [衝突とトリガーの処理](/tutorials/collision-and-triggers/): オブジェクト同士をぶつけ、何かが特定の範囲に入ったことを検出します。
- [力とインパルス](/tutorials/using-forces-on-rigid-bodies/): 物理オブジェクトを押したり回したりして動かします。
- [シーン上のエンティティの選択](/tutorials/entity-picking/): ユーザーがどのオブジェクトをクリックしたかを調べます。

さらに詳しく: [物理演算](/user-manual/physics/)

## 4. 自分のキャラクターを取り込む {#bring-in-your-own-characters}

- [最初のモデルとアニメーションのインポート方法](/tutorials/importing-first-model-and-animation/): リグ付きのキャラクターをアップロードし、そのアニメーションを再生します。
- [アニメーションステートグラフのブレンディング](/tutorials/anim-blending/): 待機や歩行などのアニメーションを滑らかにブレンドします。

さらに詳しく: [3Dモデルのインポート](/user-manual/assets/models/)と[アニメーション](/user-manual/animation/)

## 5. 光と音 {#light-and-sound}

- [ライトの制御方法](/tutorials/controlling-lights/): スクリプトからライトのオンとオフを切り替え、色と強さを変えます。
- [基本的なオーディオの設定](/tutorials/basic-audio/): シーン内のオブジェクトから聞こえる音を鳴らします。

さらに詳しく: [ライティング](/user-manual/graphics/lighting/)と[オーディオ](/user-manual/audio/)

## 6. ユーザーインターフェースを追加する {#add-a-user-interface}

- [UI - ボタン](/tutorials/ui-elements-buttons/): ホバーやクリックに反応するボタンを作ります。

さらに詳しく: [ユーザーインターフェース](/user-manual/user-interface/)

## 7. 完成したゲームを作る {#build-a-complete-game}

[シンプルなゲームの作成](/tutorials/keepyup-part-one/)では、ボールをタップして空中に保ち続けるゲーム「Keepy Up」を、スタータープロジェクトから公開まで、6つのパートで作ります。

1. [シーンのセットアップ](/tutorials/keepyup-part-one/)
2. [ライティングとマテリアル](/tutorials/keepyup-part-two/)
3. [ボールを動かす](/tutorials/keepyup-part-three/)
4. [ゲームの流れとスコア](/tutorials/keepyup-part-four/)
5. [メニュー画面とゲームオーバー画面](/tutorials/keepyup-part-five/)
6. [サウンド、パーティクル、公開](/tutorials/keepyup-part-six/)

## 8. チームで作業して公開する {#work-as-a-team-and-ship}

- [テンプレート](../templates/index.md): オブジェクトを一度作って、シーンのあちこちで再利用します。
- [リアルタイムコラボレーション](../realtime-collaboration.md): 他の人と同時に1つのシーンを作ります。
- [バージョン管理](../version-control/index.md): チェックポイントを保存し、変更をブランチで試してからマージします。
- [公開](../publishing/index.md): アプリをウェブ、アプリストア、プレイアブル広告で公開します。

## さらに探す {#find-more}

[チュートリアル](/tutorials/)ページには140以上のチュートリアルがあり、トピックで絞り込めます。細かな点を調べるときは、すべての[コンポーネント](../scenes/components/index.md)、[アセットの種類](../assets/inspectors/index.md)、[設定](../interface/settings/index.md)を説明したリファレンスページを使ってください。
