PlayCanvas Editorを初めて使う方は、ここから始めてください。次のページを順番に読むと、最初のアプリ作りからEditorの使い方を一通り身につけるまで進めます。

1. [初めてのアプリ](your-first-app.md): 小さな物理ゲームを15分ほどで作って公開します。
2. [プロジェクトの作成](../projects/creating.md): スターターキットからプロジェクトを始めるか、他の人のプロジェクトをフォークします。
3. [プロジェクトダッシュボード](../projects/dashboard.md): プロジェクトを探し、開き、管理します。
4. [Editorプロジェクトのしくみ](how-projects-work.md): シーン、エンティティ、アセット、スクリプト、ブランチ、ビルドがどう組み合わさっているかを説明します。
5. [エディターインターフェース](../interface/index.md): よく使うパネルの見取り図です。
6. [次に学ぶこと](next-steps.md): 初めてのアプリの後に進むチュートリアルとトピックの、おすすめの順番です。

## 始める前に {#before-you-start}

Editorはウェブブラウザで動くので、インストールするものはありません。必要なのは次のものです。

- [PlayCanvasアカウント](/user-manual/account-management/user-accounts/account-creation/)。このセクションの内容はすべて[Freeプラン](/user-manual/account-management/plans-and-billing/)で行えます。
- キーボードとマウスを備えた、最新のデスクトップ用ウェブブラウザ。

:::tip[Unityから移行する場合]

[Unityからの移行](/user-manual/getting-started/migrating-from-unity/)では、Unityの概念、ツール、スクリプティングがPlayCanvasの何に当たるかを説明しています。

:::
