title: プロジェクトの管理
description: "できあがったPlayCanvas Editorのプロジェクトを管理する方法です。名前、アートワーク、公開設定、Dev Logs、バックアップとエクスポート、所有権の譲渡を扱います。"
---

プロジェクトには、シーン、アセット、スクリプト、設定など、1つのアプリを構成するものがすべて入っています。このセクションのページでは、できあがったプロジェクトの管理について説明します。これらの作業のほとんどは、Editorの中ではなく、[playcanvas.com/editor](https://playcanvas.com/editor)の[プロジェクトダッシュボード](dashboard.md)で行います。

## このセクションの内容 {#in-this-section}

| ページ | 内容 |
| --- | --- |
| [プロジェクト設定](settings.md) | プロジェクトの名前、説明、アートワーク、公開か非公開かの設定。 |
| [Dev Logs](dev-logs.md) | プロジェクトをウォッチしている人とPlayCanvasのフィードに向けて、プロジェクトの近況を投稿します。 |
| [バックアップとエクスポート](backup-and-export.md) | プロジェクトをフォークまたはエクスポートしてコピーを取り、あとで復元します。 |
| [所有権と譲渡](ownership-transfers.md) | プロジェクトのオーナーができることと、別のユーザーや組織にプロジェクトを渡す方法。 |

## マニュアルの他の場所 {#elsewhere-in-the-manual}

プロジェクトに関する作業の一部は、それが必要になる場所のページにあります。

- [プロジェクトの作成](creating.md)と[プロジェクトダッシュボード](dashboard.md)は[はじめに](../getting-started/index.md)にあります。
- メンバーの追加と権限の設定を扱う[チーム管理](team-management.md)は、[リアルタイムコラボレーション](../realtime-collaboration.md)と一緒にあります。
- ビルドをダウンロードするときの形式を扱う[プロジェクトのダウンロード](downloading.md)は、[セルフホスティング](../publishing/web/self-hosting.md)と一緒にあります。
- プラン、請求、組織については[アカウント管理](/user-manual/account-management/)を参照してください。
