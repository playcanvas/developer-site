エディターのビューポートは、アプリケーションを視覚的に構築する場所です。そこから「起動」ボタンを押すと、起動ページが開き、実際にアプリケーションを*実行*できます。

![起動ボタン](/img/user-manual/editor/launch-page/launch-button.png)

## 起動 {#launching}

ビューポート右上の **Launch** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Enter</kbd>（macOS では <kbd>Cmd</kbd>+<kbd>Enter</kbd>）を押すと、起動ページが新しいタブで開きます。<kbd>Shift</kbd> を押しながら **Launch** をクリックすると、代わりにポップアップウィンドウで開きます。

**Launch** ボタンにマウスを重ねると、メニューが表示されます。

| オプション | 説明 |
| --- | --- |
| **Launch with WebGPU**<br />**Launch with WebGL 2.0** | [レンダリング設定](../settings/rendering.md#device-and-api)で設定された順序でデバイスを試す代わりに、そのグラフィックスデバイスだけを使って起動します。プロジェクトが最初に試すデバイスはメニューに表示されません。<kbd>Shift</kbd> を押しながらクリックすると、ポップアップウィンドウで開きます。 |
| **Profiler** | [Inspector](/user-manual/debugging/inspector/) を [Performance タブ](/user-manual/optimization/inspector-performance/#recording-the-start-of-the-application)で開き、アプリケーションの起動から記録します。Engine 2.23 以降が必要です。 |
| **Debug** | エンジンの警告とエラーのメッセージを、ブラウザの JavaScript コンソールに出力します。 |
| **Concatenate Scripts (Classic)** | 起動時に、プリロードされるクラシックスクリプトを 1 つのファイルにまとめ、シーンの読み込みを速くします。ESM スクリプトには影響しません。 |
| **Mini stats** | 実行中のアプリケーションに [MiniStats](/user-manual/optimization/mini-stats/) のオーバーレイを表示します。 |
| **Inspector** | 実行中のアプリケーションに [Inspector](/user-manual/debugging/inspector/) のデバッグパネルを表示します。Engine 2.23 以降が必要です。 |
| **Use Latest Engine** | エンジンの最新リリースで起動します。そのバージョンはオプションのツールチップに表示されます。Editor が最新リリースを提供している間のみ表示されます。[エンジン設定](../settings/engine.md)も参照してください。 |

オプションは、チェックを外すまですべての起動に適用されます。**Debug**、**Mini stats**、**Inspector**、**Use Latest Engine** はこのプロジェクトであなた用に記憶されますが、**Profiler** と **Concatenate Scripts (Classic)** はエディターを再読み込みするとクリアされます。

## 起動ページでの作業 {#working-with-the-launch-page}

起動ページをアクティブにすると、新しいタブで開きます。エディターと起動ページの間を行き来することは全く問題ありません。ただし、大画面やマルチモニターのセットアップをお持ちの場合は、起動ページのタブを切り離してエディターと並べて配置することを検討してください。

![起動ページを並べて表示](/img/user-manual/editor/launch-page/launch-page-side-by-side.png)

これにより、両者をより簡単かつ迅速に切り替えることができます。

## リアルタイム更新 {#real-time-updates}

起動ページの主要な機能は、エディターとのリアルタイム接続（またはライブリンク）を維持していることです。エディターで行ったほとんどの変更は、再読み込みしなくても起動ページに即座に反映されます。

- **エンティティ**: 作成、削除、名前の変更、移動、親の変更、有効化と無効化。リジッドボディを持つエンティティを移動すると、エンティティはその位置にテレポートし、速度がリセットされます。
- **コンポーネント**: 追加と削除、プロパティの編集。スクリプトの追加、削除、有効化、並べ替えと、スクリプト属性の編集も含まれます。
- **アセット**: マテリアルの編集やテクスチャの置き換えなどの変更。
- **設定**: 重力、スカイボックス、フォグ、露出などのシーン設定と、解像度、レイヤー、バッチグループ、ローカライズ用アセットなどのプロジェクト設定。

![起動ページのライブリンク](/img/user-manual/editor/launch-page/launch-page-live-link.gif)

また、他のユーザー（書き込み権限を持つ）があなたと一緒にエディターにいる場合、彼らの編集もあなたの起動ページを更新することができます。

次の変更は、起動ページを再読み込みしたときに反映されます。

- **コードの変更**: スクリプトを保存しても、実行中のアプリケーションは更新されません。ただし、スクリプトが[ホットリロード](../../scripting/hot-reloading.md)用の `swap()` を実装している場合は除きます。
- **新しいスクリプト**: 起動後に作成またはアップロードしたスクリプトアセットは、再読み込みするまで読み込まれません。
- **別のシーン**: 起動ページは、起動したシーンを実行し続けます。別のシーンを実行するには、そのシーンをエディターで開いてから再度起動します。
- **起動時の設定**: アプリケーションが起動時に読み込む設定です。たとえば、[レンダリング設定](../settings/rendering.md#device-and-api)のグラフィックスデバイスの設定、[入力設定](../settings/input.md)、[ローディング画面](loading-screen.md)、外部スクリプト、インポートマップなどです。**Clustered Lighting** をオンまたはオフにした場合は、エディターと起動ページの両方を再読み込みする必要があります。

:::ai
再現手順と期待する動作をAIアシスタントに伝えると、[**Editor MCP Server**](/user-manual/editor/mcp-server/)で入力を再現し、修正前後のログ、エンティティ状態、キャプチャを関連付けて比較できます。
:::

## 他のデバイスでの実行 {#running-on-other-devices}

場合によっては、起動ページを別のデバイスで実行すると便利な場合があります。例えば、モバイルデバイスでアプリケーションをテストしたいと思うかもしれません。これを行うには、そのデバイスでPlayCanvasアカウントにログインしていることを確認してください。その後、そのデバイスのブラウザで起動ページのURLにアクセスするだけです。

:::tip

Chromeは任意のページのQRコードを動的に生成できます。デスクトップの起動ページから、Chromeのメインメニューを開き、「`共有と保存`」 > 「`QRコードを作成`」を選択します。その後、モバイルデバイスでQRコードをスキャンして、即座に起動ページにアクセスしてください。

:::
