Mac では、CTRL の代わりに CMD を、ALT の代わりに OPTION を使用します。

## カメラコントロール {#camera-controls}

エディターのカメラはマウスとキーボードで操作します。移動キーは、キーボードのフォーカスがテキストフィールドにない限り、マウスボタンを押さなくても単独で機能します。

| 操作 | コントロール |
| --- | --- |
| 回転 | 左クリック+ドラッグ |
| パン (Pan) | 中央クリック+ドラッグ<br />SHIFT + 左クリック+ドラッグ |
| 視点変更 | 右クリック+ドラッグ |
| ズーム (Zoom) / ドリー (Dolly) | マウスホイール |
| ズーム (高速) | ALT + マウスホイール |
| 移動 | W-A-S-D<br />矢印キー |
| 下へ / 上へ移動 | Q / E<br />PAGE DOWN / PAGE UP |
| 移動 (高速) | 移動中に SHIFT を押し続ける |

正投影ビュー（Top、Bottom、Front、Back、Left、Right）では、左または右のマウスボタンでドラッグするとビューがパンし、W と S でビューが上下に移動します。

## ビューポートのカメラ {#viewport-cameras}

Num Lock をオンにした状態でテンキーを使って、エディターの[カメラ](viewport.md#cameras)を切り替えます。CTRL を押しながら操作すると、反対側からシーンを表示します。

| 操作 | キーボードショートカット |
| --- | --- |
| 前面 / 背面ビュー | NUMPAD 1 / CTRL + NUMPAD 1 |
| 右側 / 左側ビュー | NUMPAD 3 / CTRL + NUMPAD 3 |
| 上部 / 下部ビュー | NUMPAD 7 / CTRL + NUMPAD 7 |
| 透視投影 / 正投影の切り替え | NUMPAD 5 |
| 透視投影ビュー | NUMPAD 0 |

NUMPAD 5 を押すと正投影ビューから Perspective カメラに切り替わり、もう一度押すとその正投影ビューに戻ります。Perspective カメラのまま軸に沿った向きにするには、[View Cube](viewport.md#view-cube) をクリックします。

## マウス操作 {#general-mouse-controls}

| 操作 | コントロール |
| --- | --- |
| エンティティの選択 | 左クリック |
| 選択へのエンティティの追加 / 選択からの除外 | CTRL + 左クリック |
| 矩形選択 | CTRL + 左クリック+ドラッグ |
| エンティティの移動 / 回転 / スケール (ギズモに応じたもの) | 左クリック+ドラッグ |

矩形選択では、矩形の内側に描画されているエンティティが選択され、現在の選択と置き換わります。

## 修飾キー {#general-modifier-keys}

| 操作 | コントロール |
| --- | --- |
| ギズモの操作中にエディターのスナップ設定を切り替え | エンティティをドラッグ中に SHIFT を押す |
| 親を変更する際にエンティティの変換を維持しない | エンティティの親を変更する際に CTRL を押す |
| 起動ページまたはコードエディターをポップアップウィンドウで開く | Launch ボタンまたは Code Editor ボタンをクリックする際に SHIFT を押す |

## キーボードショートカット {#keyboard-shortcuts}

| 操作 | 説明 | キーボードショートカット |
| --- | --- | --- |
| 起動 | シーンを新規タブで起動します。 | CTRL + ENTER |
| 新規エンティティ | 選択しているエンティティの子として新規エンティティを作成します。エンティティを選択していない場合は、シーンのルートに作成します。 | CTRL + E |
| エンティティを複製 | 選択されたエンティティとそのすべての子を複製します。 | CTRL + D |
| エンティティ名の変更 | 選択しているエンティティの名前フィールドにフォーカスします。 | F2 |
| アセット名の変更 | 選択しているアセットの名前フィールドにフォーカスします。 | N または F2 |
| すべて選択 | エンティティを選択している場合はシーン内のすべてのエンティティを、アセットを選択している場合は Assets パネルに表示されているすべてのアセットを選択します。 | CTRL + A |
| エンティティ / アセットのコピー | 現在のエンティティ/アセットの選択項目をコピーします。 | CTRL + C |
| エンティティ / アセットの貼り付け | コピーしたエンティティ/アセットを現在選択されているエンティティ/フォルダの下に貼り付けます。 | CTRL + V |
| アセットの貼り付け (フォルダを維持) | コピーしたアセットを、[フォルダ構造](../assets/asset-panel.md#copy-and-paste-between-projects)を維持したまま貼り付けます。 | CTRL + SHIFT + V |
| 削除 | 現在の選択項目を削除します。 | DELETE<br />CTRL + BACKSPACE |
| 親フォルダ | Assets パネルで 1 つ上のフォルダに移動します。 | BACKSPACE |
| 選択をフレーム表示 | 3D ビューで、現在選択しているエンティティにフォーカスします。 | F |
| 移動 | 3D ビューで移動ギズモをアクティブにします。 | 1 |
| 回転 | 3D ビューで回転ギズモをアクティブにします。 | 2 |
| スケール (Scale) | 3D ビューで拡大縮小ギズモをアクティブにします。 | 3 |
| エレメントのサイズ変更 | 3D ビューで、[UI エレメントのサイズを変更](/user-manual/user-interface/elements/#element-resizing)するギズモをアクティブにします。 | 4 |
| World / Local | ローカル座標系とワールド座標系のギズモを切り替えます。 | L |
| パネル表示/非表示 | すべてのパネルを非表示にしたり表示したりして、3D ビューを最大化します。 | SPACE |
| ベイク | [ランタイムライトマッパー](/user-manual/graphics/lighting/runtime-lightmaps)を使用してライティングを再ベイクします。 | CTRL + B |
| 前の選択 | 前に選択していた項目を選択します。 | SHIFT + X |
| 元に戻す | 最後のアクションを元に戻します。 | CTRL + Z |
| やり直し | 最後の操作をやり直します。 | CTRL + Y<br />CTRL + SHIFT + Z |
| 新規チェックポイント | Version Control パネルを開き、[チェックポイントを作成](../version-control/checkpoints.md#creating-a-checkpoint)するフォームを表示します。 | CTRL + S |
| コードエディター | [コードエディター](../scripting/code-editor.md)を開きます。 | CTRL + I |
| プロジェクト | プロジェクトページに切り替えます。開いていない場合は新しいタブで開きます。 | CTRL + O |
| どうすれば...？ | ミニチュートリアルの検索ツールバーの切り替え | CTRL + SPACE |
| コントロールを表示 | エディターのコントロールを表示します。 | SHIFT + ? |
