設定パネルは、プロジェクトの実行方法とエディターの挙動を制御します。各設定は、次の 3 つのスコープのいずれかに属します。

- **シーン**: 開いているシーンに保存されるため、シーンごとに異なる値を使用できます。重力、環境（アンビエントカラーとスカイボックス）、クラスタードライティング、ガウシアンスプラットのレンダリング、露出、フォグ、ライトマッピングはシーン設定です。
- **プロジェクト**: プロジェクト内のすべてのシーンで共有されます。解像度、グラフィックスデバイス、アンチエイリアス、レイヤー、バッチグループ、入力デバイスなどです。
- **あなた**: あなた個人にのみ適用される設定です。エディター設定やアセットインポートのオプションなどです。

シーン設定とプロジェクト設定は、現在の[ブランチ](../../version-control/branches.md)の全コラボレーターに影響します。各パネルのヘッダーのアイコンは、そのパネルがあなたにのみ影響するのか、ブランチの全員に影響するのかを示します。ヘッダーにマウスを重ねると、どちらなのかが表示されます。

## 設定を開く {#opening-settings}

[ツールバー](../toolbar) または [ビューポート](../viewport) の「歯車」アイコンをクリックするか、メインメニューで **Settings** を選択して、[インスペクター](../inspector) に設定を読み込みます。

![Settings](/img/user-manual/editor/interface/toolbar/settings.png)

## 設定カテゴリ概要 {#settings-overview}

設定の一番上にある **Scene Name** フィールドで、現在のシーンの名前を変更できます。その下には、設定がカテゴリごとに折りたたみ可能なパネルとして表示され、インスペクターでは次の順に並びます。

| パネル | 説明 | スコープ |
| --- | --- | --- |
| [エンジン](engine.md) | エンジンの設定（エンジンバージョンなど）。 | あなた（現在のセッションのみ） |
| [エディター](editor.md) | カメラの近/遠クリップ、ズーム感度、ギズモ、View Cube などエディター関連の設定。 | あなた |
| Version Control | バージョン管理の設定。たとえば **Auto-Load Diffs** は、[バージョン管理](../../version-control/index.md)パネルで差分を自動的に計算して表示します。差分の生成に時間がかかる非常に大きなプロジェクトでは無効にしてください。 | あなた |
| [アセットインポート](asset-import.md) | アセットのインポート方法を制御する設定。 | あなた |
| [物理](physics.md) | 物理ライブラリの追加や重力設定など。 | 重力: シーン<br />Physics Library: プロジェクト |
| [レンダリング](rendering.md) | スカイボックス、クラスタードライティング、シャドウ、解像度、グラフィックスデバイスの設定など。 | 環境、ライティング、スプラット、露出、フォグ: シーン<br />解像度、デバイス、キャンバスのオプション: プロジェクト |
| [レイヤー](layers.md) | レンダリングレイヤーとその順序の管理。 | プロジェクト |
| [ライトマッピング](lightmapping.md) | 解像度、モード、アンビエントベイクなどの設定。 | シーン |
| [バッチグループ](batch-groups.md) | バッチグループの管理。類似メッシュや要素をまとめてドローコールを削減します。 | プロジェクト |
| Loading Screen | アプリケーションの[ローディング画面](../launch-page/loading-screen.md)を作成するスクリプト。 | プロジェクト |
| Import Map | ESM スクリプト内のモジュール指定子を解決する[インポートマップ](../../scripting/import-maps.md)。 | プロジェクト |
| External Scripts | アプリケーションに含める外部スクリプトの URL。アプリケーションのページに `<script>` タグとして追加され、他のどのスクリプトよりも先に読み込まれます。 | プロジェクト |
| [起動ページ](launch-page.md) | ランチ（起動）ページに関する設定。 | プロジェクト |
| [入力](input.md) | 入力デバイス（マウス、キーボードなど）の有効化/無効化。 | プロジェクト |
| [ローカライゼーション](localization.md) | ローカライズ用アセットの設定。 | プロジェクト |
| [ネットワーク](network.md) | プロジェクトのネットワーク関連の設定。 | プロジェクト |
| Scripts Loading Order | プリロードされるスクリプトを読み込む順序。[スクリプトのロード順序](../../scripting/loading-order.md)を参照してください。 | プロジェクト |
| Project Settings History | バージョン管理パネルで、プロジェクト設定の[履歴](../../version-control/item-history.md)を開きます。 | プロジェクト |

:::ai
設定が予期しない動作の原因と思われる場合は、AIアシスタントに[**Editor MCP Server**](/user-manual/editor/mcp-server/)で関連する設定とスコープを特定させ、適用前に最小限の変更を説明させます。
:::
