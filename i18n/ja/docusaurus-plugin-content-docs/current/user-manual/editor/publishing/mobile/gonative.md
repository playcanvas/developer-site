[Median.co](https://median.co/)（2023年まではGoNativeという名前でした）は、ウェブアドレスをもとにネイティブのモバイルアプリを作る有料のサードパーティーサービスです。作られたアプリは、PlayCanvasのアプリをネイティブのWebViewで表示します。

アプリはPlayCanvasのアプリをウェブアドレスから読み込むので、プレイヤーはオンラインである必要があり、アプリをどこかでホストしておく必要があります。[PlayCanvasホスティング](../web/playcanvas-hosting.md)か[自分のサーバー](../web/self-hosting.md)を使ってください。

Median.coには、PlayCanvasのアプリから広告やアプリ内課金などのネイティブ機能を使えるようにする[プラグイン](https://median.co/plugins)もあります。
