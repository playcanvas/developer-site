---
title: デスクトップ
description: "PlayCanvas EditorのアプリをNW.jsでWindows、macOS、Linuxのデスクトップアプリとしてパッケージする方法です。"
---

PlayCanvasのアプリはそのままデスクトップブラウザで動きます。ゲームストアなどで、Windows、macOS、Linuxにインストールするアプリとして出すには、ブラウザエンジンとアプリを一緒にまとめるツールでパッケージします。

[NW.js](https://nwjs.io/)をおすすめします。

1. プロジェクトのビルドをstatic形式で[ダウンロード](../../projects/downloading.md)します。
2. NW.jsでパッケージします。OSごとのアプリの作り方は[NW.jsのドキュメント](https://github.com/nwjs/nw.js/wiki/How-to-package-and-distribute-your-apps)で説明しています。

ブラウザの場合と同じように、パッケージしたアプリは出荷先の各OSでテストしてください。
