[heyVR](https://heyvr.io) is a platform for publishing WebXR games, which players open on VR headsets and other devices. Its optional SDK adds features such as leaderboards, cloud saves, multiplayer, in-game purchases and ads.

To build a game for VR headsets, see [XR](/user-manual/xr/).

## Publishing Flow {#publishing-flow}

### 1. Create a developer account {#create-a-developer-account}

Register for free in heyVR's [Developer Area](https://developer.heyvr.io). Once you're signed in, you can create and manage your games there.

### 2. Make a zip file of your build {#make-a-zip-file-of-your-build}

[Make a build](index.md#making-a-build) of your game, then zip the contents of the build folder, so that `index.html` is at the root of the zip file rather than inside a folder.

### 3. Upload your game {#upload-your-game}

Create your game in the Developer Area and upload the zip file. heyVR's guide to [publishing a game](https://docs.heyvr.io/en/developer-area/publish-a-game) covers each step, its requirements and common questions.

### 4. Publish {#publish}

Once your game is uploaded, you can open and test it on heyVR. When it's ready, submit it for review. heyVR checks that it works and that it follows its [Publishing Guidelines](https://heyvr.io/hc/legal/heyvr-io-publishing-policies) before making it public.

## SDK Features (optional) {#sdk-features}

The [heyVR SDK](https://docs.heyvr.io/en/game-development/sdk) gives your game access to:

- User management
- Leaderboards
- Cloud saves
- In-game purchases, both free and paid
- In-game ads
- Multiplayer

The SDK documentation explains how to add it to your game and use each feature.
