If you're new to the PlayCanvas Editor, start here. These pages take you from your first app to knowing your way around, in this order:

1. [Your First App](your-first-app.md): build and publish a small physics game in about 15 minutes.
2. [Creating Projects](../projects/creating.md): start a project from a starter kit, or fork someone else's.
3. [Project Dashboard](../projects/dashboard.md): find, open and manage your projects.
4. [How Editor Projects Work](how-projects-work.md): how scenes, entities, assets, scripts, branches and builds fit together.
5. [Editor Interface](../interface/index.md): a map of the panels you'll use most.
6. [What to Learn Next](next-steps.md): a suggested order for the tutorials and topics that come after your first app.

## Before You Start {#before-you-start}

The Editor runs in your web browser, so there's nothing to install. You need:

- A [PlayCanvas account](/user-manual/account-management/user-accounts/account-creation/). The [Free plan](/user-manual/account-management/plans-and-billing/) is enough for everything in this section.
- An up-to-date desktop web browser, with a keyboard and mouse.

:::tip[Coming from Unity?]

[Migrating from Unity](/user-manual/getting-started/migrating-from-unity/) maps Unity's concepts, tools and scripting to their PlayCanvas equivalents.

:::
