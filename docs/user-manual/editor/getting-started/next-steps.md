After [Your First App](your-first-app.md), these tutorials cover what most projects need next. They're grouped by goal, and each group builds on the ones before it, so working through them in order is a good way to learn the Editor. If you already know what you want to make, jump straight to the goal that matches. Each group ends with the manual chapter that explains its topic in depth.

## 1. Control Things with Code {#control-things-with-code}

- [Manipulating Entities](/tutorials/manipulating-entities/): move, rotate and scale entities from a script, and see how children follow their parents.
- [Basic Keyboard Input](/tutorials/keyboard-input/): react when keys are pressed and held.
- [Basic Mouse Input](/tutorials/mouse-input/): read mouse movement and button presses.

Go deeper: [Scripting](/user-manual/scripting/) covers the script lifecycle, attributes and events.

## 2. Frame the Action {#frame-the-action}

- [Basic Cameras](/tutorials/basic-cameras/): add a camera and set it up so your scene renders.
- [More Cameras](/tutorials/more-cameras/): zoom, move and switch cameras from a script while the app runs.

Go deeper: [Cameras](/user-manual/graphics/cameras/).

## 3. Collide and Push {#collide-and-push}

- [Collision and Triggers](/tutorials/collision-and-triggers/): make objects bump into each other, and detect when something enters an area.
- [Forces and Impulses](/tutorials/using-forces-on-rigid-bodies/): move physics objects by pushing and spinning them.
- [Entity Picking](/tutorials/entity-picking/): find out which object the user clicked.

Go deeper: [Physics](/user-manual/physics/).

## 4. Bring In Your Own Characters {#bring-in-your-own-characters}

- [Importing your first Model and Animation](/tutorials/importing-first-model-and-animation/): upload a rigged character and play its animations.
- [Anim State Graph Blending](/tutorials/anim-blending/): blend smoothly between idle, walk and other animations.

Go deeper: [Importing 3D Models](/user-manual/assets/models/) and [Animation](/user-manual/animation/).

## 5. Light and Sound {#light-and-sound}

- [Controlling Lights](/tutorials/controlling-lights/): switch lights on and off, and change their color and intensity, from a script.
- [Basic Audio](/tutorials/basic-audio/): play sounds that come from objects in the scene.

Go deeper: [Lighting](/user-manual/graphics/lighting/) and [Audio](/user-manual/audio/).

## 6. Add a User Interface {#add-a-user-interface}

- [User Interface - Buttons](/tutorials/ui-elements-buttons/): build buttons that respond to hovering and clicks.

Go deeper: [User Interface](/user-manual/user-interface/).

## 7. Build a Complete Game {#build-a-complete-game}

[Making a Simple Game](/tutorials/keepyup-part-one/) has you build Keepy Up, a game where you tap a ball to keep it in the air, from a starter project to a published game in six parts:

1. [Setting up the scene](/tutorials/keepyup-part-one/)
2. [Lighting and materials](/tutorials/keepyup-part-two/)
3. [Making the ball move](/tutorials/keepyup-part-three/)
4. [Game flow and scoring](/tutorials/keepyup-part-four/)
5. [Menu and game over screens](/tutorials/keepyup-part-five/)
6. [Sound, particles and publishing](/tutorials/keepyup-part-six/)

## 8. Work as a Team and Ship {#work-as-a-team-and-ship}

- [Templates](../templates/index.md): build an object once and reuse it throughout your scenes.
- [Real-time Collaboration](../realtime-collaboration.md): build a scene with other people at the same time.
- [Version Control](../version-control/index.md): save checkpoints, and try changes on a branch before merging them.
- [Publishing](../publishing/index.md): put your app on the web, in an app store or in a playable ad.

## Find More {#find-more}

The [Tutorials](/tutorials/) page has more than 140 tutorials, which you can filter by topic. To look up a detail, the reference pages document every [component](../scenes/components/index.md), [asset type](../assets/inspectors/index.md) and [setting](../interface/settings/index.md).
