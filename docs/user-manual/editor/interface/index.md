![Editor Interface](/img/user-manual/editor/interface/editor-interface.png)

This is the main interface to the PlayCanvas Editor. The numbered areas above are:

1. [**Toolbar**](toolbar.md) Commonly used commands are available on the toolbar for quick access.
2. [**Hierarchy**](hierarchy.md) A hierarchical view of the Entities that make up the open Scene. Use this to select, delete and re-parent Entities.
3. [**Viewport**](viewport.md) A 3D view onto your scene, use this view to select, position and orientate Entities.
4. [**Inspector**](inspector.md) Detailed properties of the selected [Entity](/user-manual/glossary#entity), [Asset](/user-manual/glossary#asset) or [Component](/user-manual/glossary#component).
5. [**Assets**](assets.md) A view of all the Assets in the current Project. You can search for assets by name, filter by type and also drag and drop assets to various slots or in the Design View.
